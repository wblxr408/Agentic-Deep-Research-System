# Proposal

## Why

ADRS 当前提供通用研究入口，缺少面向企业、高校和科研实验室的明确研究范围、学科评价口径与可解释匹配。用户要求跨学科评价、可调权重和对象单选／多选，并进一步要求从采集与计数深入到研究路线、成果机制、证据交叉验证及行动建议；需要形成跨对象、跨学科的可实施契约和分期计划。

## What Changes

- 新增“组织研究发展分析”模式，支持高校、科研实验室、企业三类对象任意非空组合，也支持一个或多个具体研究对象；高校和实验室可独立分析。
- 支持单个／多个学科、技术主题、时间范围、对象发展分析与多对象比较，分别保留对象归属和去重汇总。
- 适配 CCF、ICORE、WoS／Scopus 收录、JCR、期刊分区表（中科院分区）、CiteScore、SJR、SNIP、ABDC、AJG，以及论文级引用百分位、CNCI、FWCI。不同体系独立保留原始值、适用范围、类别、版本与来源。
- 提供主题相关性、研究路线契合、成果表现、证据完整度、时效性和合作互补性等可调匹配维度；成果表现内各适用体系也能设置权重。支持预设与自定义、启停、归一化和贡献解释，明确缺失数据及不可比情况。
- 前端展示类型多选、具体对象选择、学科和指标适用性、权重面板及排名变化；请求、状态、报告保存不可变的配置快照。
- 记录用户可见的筛选理由、匹配依据和待核项；权重不能覆盖硬性条件或把未知事实变为已证实关系。
- 增加布局与演进、合作资源发现、综合研究三种目的，按需组合样本界定、版本化分类、组织人员关系、代表成果机制深读、趋势情景与外部验证；单独研究高校或实验室不要求企业／产品／合作页。
- 增加可复算统计、分子分母和多标签口径；按目的输出研究验证路线或有证据的合作切入点。区分公开活动与内部战略、共著与正式合作、应用相关与已部署，模板和绘图候选沿用优化 TODO 的后续规划。
- 规划材料已交付；2026-10-19 实施推进至 3.5：范围／家族／关系、评价适配、权重与实际匹配／区间／重排已交付，研究链路、前端及其他任务保持待实现。接口与真实来源覆盖边界见 [范围预览](../../../docs/organization-research-scope.md)、[评价／权重](../../../docs/research-evaluation-and-weights.md)和[owner 快照匹配 ACI](../../../docs/research-matching-preview.md)。

## Capabilities

### New Capabilities

- `organization-research-scope`: 组织研究目的与范围、对象单选／多选、跨学科分类、实体归属、样本覆盖、成果深读、演进与可复算统计。
- `discipline-evaluation`: 跨学科评价体系及版本化、来源化的成果标签和可用性状态。
- `weighted-research-matching`: 可调权重、硬条件、可解释匹配、缺失处理、可选行动建议，以及会话和报告中的配置快照。

### Modified Capabilities

无。主规范清单目前为空；既有来源策略、执行边界和渠道变更中的有效契约继续适用。

## Impact

- 计划扩展 `app/api/research.py` 请求与响应、`app/graph/state.py` 和现有持久化中的组织研究配置及结果，复用当前搜索、浏览、分析和报告调用点。
- 计划增加紧凑的组织／评价／匹配数据契约和普通函数，不因本需求增加 Agent 或独立编排框架。
- 分析能力复用既有采集、综合和引用审计，来源不足显示覆盖与推断边界；不安装新的技能包或发起对外联系。
- 计划扩展 `frontend/src/components/ResearchDashboard.tsx` 和 `ReportPreview.tsx`；研究对象选择与已有联网渠道选择分别建模。
- 数据源通过公开或已授权资料及现有渠道接入；未取得授权或无法核实的指标明确标记缺口，不承诺所有外部数据已经可用。
- 新模式为可选配置，旧通用请求可继续使用；内部资料归属、预算、审批及恢复仍遵循现有边界。
- 实现路线见 `docs/RESEARCH_DEVELOPMENT_PLAN.md`；OpenMinion 参赛运行接入另行规划，不将其声称为本变更已实现能力。
