# Design

## Context

动机见[proposal](proposal.md)。OPT-02提供规范text、blocks、表格／图像和解析版本；现有上传 `_chunk_text` 没有区间，RAG结果metadata虽可携带来源ID但未贯通父级与报告引用。任务账本已保留各证据文字版本，适合作旧报告引用的锚点。

## Goals / Non-Goals

**Goals:** 以普通数据计划连接原文、块、可选父级上下文、可选语义切块、抽取式摘要、实体候选及稳定引用，避免重复存正文和无理由重复生成嵌入。

**Non-Goals:** 不增加Agent或向量服务，不按共现确认实体关系，也不以结构／偏移校验宣称语义事实已审核。语义模型和实体抽取仅在本人选择时执行；摘要与模型派生元数据不替代原文。

## Decisions

### 1. 统一版本块计划

普通函数接受规范原文、实际解析结构与分块策略，返回根／章节／表格／代码父块和小块。块ID由实际资料／解析版本、策略及区间构造；原文只存一次。默认结构边界，纯文本可用固定、滑动或按分隔符递归。长结构分出有界子块并保存父级。不默认模型语义切块，因为尚无准确率／成本收益依据。

### 2. 元数据和分类分别保留依据

标题路径、源摘录、页／结构定位单列，不插入原片段文本造成偏移漂移。规则抽取字典实体、日期、DOI／URL，标记仅提及；复用taxonomy校验和词面匹配生成可选问题／方法／应用及核心／关联多标签，明确这是文档块词面，不是组织成果题名／摘要分类或官方评价。无规则／无来源保持未知。

### 3. 父级只在当前权限与预算内展开

小块仍为主要索引单位，父级存原范围而不重复嵌入。扩展时服务端按实际owner、资料分组、来源状态及解析版本复核，并返回覆盖命中小块的有界原文窗口；失败退回原片段并解释。旧无定位片段不通过文本搜索猜父级。取证源仍默认任务内保存，不因块计划自动进入跨任务RAG。

### 4. 报告引用任务保留证据

Citation保存evidence_id与实际摘录范围；内部资料附来源／解析／逻辑块及原文区间。本人可通过只读任务证据API消费旧原文，不依赖后来的索引。原主张审核已有excerpt_id／evidence_id／区间，沿同一定位补足数据，不替代独立语义核实。JSON导出与界面保留定位，离线显示实际已保存摘录。

### 5. 存储与兼容

继续现有JSONB和documents表。来源metadata保存块计划，索引行只存本块元数据／父级引用；幂等键加入分块策略，重切形成独立来源表示。旧无计划资料可显示明确缺口，不隐式重写旧文本／索引。没有迁移或后台重切任务。

### 6. 安全及实施时序

复用A2ABreak v1.0全11项适用性。A2AB-03《上下文归属与跨租户隔离》用于小块／父源／任务引用owner校验；A2AB-06《并发状态版本与审批绑定》用于不可变版本与已有事务幂等；A2AB-08《结构化授权请求与权限不放大》用于扩展仍限制原分组；A2AB-10《委派环路检测与全链预算》用于有限上下文与无新增模型调用，引用各方案“工程解决方案／验收办法”，来源见[TODO](../../../docs/OPTIMIZATION_TODO.md#安全方案引用与规划状态)。无新A2A／流／回调／委派，其余项沿用原评估。当前只实施，所有行为到全部TODO实现后统一端到端。

## Risks / Trade-offs

- [切块或标题识别不足] → 元数据质量及显式策略，保留根文本，不把启发式当语义准确率。
- [父级过大或包含噪声] → 明确选择、字符上限及命中区间，默认不强制扩展。
- [旧索引无区间] → 保留片段可读，但位置／父级未知；由新显式接入产生独立新版本。
- [元数据膨胀] → 父级和全文只存一次，块只带有界字段及引用。

## Migration Plan

新策略进入既有接入事务，老来源／报告不改写。新增只读端点和Citation可选字段兼容旧数据；来源状态或版本不成立时拒绝扩展。依赖、服务加载及真实检索／报告验证留到全部实现之后。

## 7. 按完整 TODO 补齐语义切块及上下文（2026-10-27）

语义切块为显式策略，复用已配置且固定版本的本地 `SentenceTransformer` 编码器，按有界相邻原文单元的相似度和长度产生断点，并保留章节／表格边界；不将词面相似包装为模型语义。记录实际模型／版本、单元覆盖、阈值和断点，编码不可用或截断时拒绝该策略而非冒充语义结果；不自动下载额外模型，普通结构切块保持默认。块始终只引用实际原文区间，重切产生独立表示。

文档摘要先采用完全可回到原文的抽取句，位置与来源版本单列，只有用户显式启用时随同有限上下文返回；模型候选和词典实体均以来源区间为依据，无法唯一定位的文字保持未知，不用共现推断关系。模型实体抽取复用既有本人资料处理操作、认证模型、单次额度与取消／版本边界；实体记录必须验证原文位置，作为候选与字典词面分开。当前是新增设计，代码及真实端到端分开跟踪。
