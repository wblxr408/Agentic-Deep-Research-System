# Design

## Context

见 proposal.md。原有 channels 的 HttpReader 已固定 DNS 地址并验证公共 HTTPS，但通用 Playwright 绕过它。LangGraph 每次编译新检查点，API 错误累加增量并调用不存在的恢复节点。会话 UPSERT 没有运行状态约束，SSE 仅在建立连接鉴权。

## Goals / Non-Goals

**Goals:** 完成六项缺陷修复；使用实际状态和动作绑定保证恢复；在数据库事务内串行化同一会话的启动与审批。

**Non-Goals:** 扩大研究工具权限或执行回归套件；新建 A2A 协议和委派系统。

## Decisions

- 浏览器网络通过固定地址的公共 HTTPS 传输，由 Playwright 拦截并交付响应；关闭 service worker、WebSocket 等绕行入口，保留正常 JavaScript 渲染。单纯校验 URL 后让浏览器自行解析 DNS 存在重绑定窗口。
- RAGResult 接受已有 Citation 及旧字符串引用，保留兼容调用方。
- 使用实际完整图状态持久化，新增合法恢复入口；审批只绑定原 node/tool/payload，保留已消耗预算与 skill_context。仅从暂停状态恢复，全部待审批决定完成后继续，拒绝动作成为跳过节点。
- 会话原子 INSERT，已有会话仅允许 owner 相符且待确认、请求内容相符时原子确认；其余返回冲突。审批使用会话行锁和一次性决定，避免并行启动两个恢复任务。
- SSE 捕获最初使用的凭据身份，在历史/新事件交付前和等待中重新读取凭据有效性及 owner；失效或后端检查失败则关闭。
- 空批次显式进入汇总和报告，给出可读受限结果。

## Security Baseline

应用本地 A2AB v1.0（已核实方案，待项目验证，并非官方修复宣称），引用方案的“工程解决方案 / 验收办法”：A2AB-03《上下文归属与跨租户隔离》约束恢复 owner；A2AB-04《长连接撤权与事件出口鉴权》约束 SSE；A2AB-06《并发状态版本与审批绑定》约束会话行锁、动作绑定及一次性恢复；A2AB-07《Webhook归属验证与受控出站》仅适用受控出站部分，约束浏览器固定地址传输；A2AB-08《结构化授权请求与权限不放大》约束 approved node/tool/payload；A2AB-10《委派环路检测与全链预算》仅复用全链预算连续性。验证点为本次对应最小行为用例。

复用 add-research-channels/design.md 的其余方案评估：01/02/05/09 无新增发现/身份/跨组织委派流程，11 无新增任务租约机制；07 webhook 和10 委派环路不适用。

## Risks / Trade-offs

- 公共浏览器出站仅支持 HTTPS GET/HEAD，写入和实时 WebSocket 拒绝，符合研究只读边界。
- 旧版不完整暂停快照无法安全推断原授权 → 返回明确冲突，不从空查询重新启动。
- 数据库原子并发行为和真实浏览器环境需要有明确验证证据；当前用例仅覆盖六项修复的最小契约，遵守禁止回归测试要求。

## Migration Plan

保持现有数据和脏工作区，新增请求绑定字段使用数据库初始化的幂等迁移；旧会话不允许未经绑定的重复启动。失败可回滚本变更的独立补丁，不回滚已有 channels/RAG 修改。
