# Proposal

## Why

当前内部资料检索被强制放到联网之前，返回任意片段即可默认跳过搜索和浏览，导致公开研究被知识库覆盖范围限制。将内部资料检索改为用户按需启用的证据补充能力，使公开研究默认联网。

## What Changes

- 新增默认关闭的 `use_internal_docs` 请求选项；保留 `rag_group` 作为启用后的资料分组过滤。
- 取消强制插入 RAG 前置节点、联网依赖及命中后跳过联网的策略，规划和重规划均执行新契约。
- 服务端限制未启用的内部检索，启用后继续联网并合并两类证据；保持技能许可、用户隔离与预算约束。
- 前端提供“补充检索内部资料”开关和条件可用的分组输入，统一知识库和研究界面的说明。
- **BREAKING**：`allow_web_after_rag_hit` 不再控制行为；旧客户端提交该字段将被忽略，旧状态中该字段也不能恢复跳过联网策略。
- 更新 README、技术规格、讲解、部署及模型文档，说明资料来源、按需模型加载和历史报告需手动入库的边界。

## Capabilities

### New Capabilities

- `research-source-policy`: 公开研究默认联网、内部资料明确启用、调度独立于内部检索命中，以及前后端选项与恢复行为。

### Modified Capabilities

无现有主规格需要修改。

## Impact

涉及 Planner、图调度与状态、研究 API 的请求/后台/恢复路径、研究与资料管理前端、行为测试和项目文档。复用已有检索、渠道、租户隔离和预算实现，不新增依赖或自动研究成果入库。
