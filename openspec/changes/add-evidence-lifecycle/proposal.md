# Proposal

## Why

OPT-06要求更新资料后能追踪原文、表示及索引的生效版本。当前仅能修改标签或永久删除来源，缺少可恢复删除、版本关联、明确复用范围及失效传播。

## What Changes

- 保留物理来源内容不可变，新内容／局部修订生成独立版本，版本族明确当前项；原报告引用不随新内容改写。
- 新来源默认任务范围；明确选择分组或本人跨任务复用才允许相应查询。未绑定任务的任务资料只能定位，当前任务身份由执行器提供。
- 加入有效期、Tombstone、恢复、原子批量切换、显式物理清理、owner访问版本及修订事件，查询和父级扩展复核当前状态。
- 用现有同事务增量索引和重建，明确不采用无需求的后台重训／压缩服务；提供状态、修订原因及受影响报告关联。
- 同步ACI、界面和未运行状态，最后统一端到端。

## Capabilities

### New Capabilities

- `evidence-lifecycle`：来源版本、保存／复用范围、生效期、可恢复删除及当前授权传播。

### Modified Capabilities

无已发布主规范修改；补充在途索引与任务证据契约。

## Impact

现有PostgreSQL增加来源生命周期／事件和访问epoch，挂接初始化及迁移；资料API、RAG三通道、父级扩展、服务端会话传递及前端资料管理。**BREAKING**：DELETE来源改为可恢复Tombstone；永久清理改用本人显式生命周期动作。新增资料未明确跨任务复用且未绑定任务时不加入跨任务召回。无新Agent、索引服务或常驻清理器。
