# Proposal

## Why

现有前端以配置表单和运行日志为中心，研究过程难以阅读，报告与运行信息混杂。用户已确定四套背景、黑色蒙版、中英文主副标题及组件参考，现要求完整实现统一的研究工作区。

## What Changes

- 从用户指定 Skill 书架筛选全部研究相关方法，固定来源与版本，适配现有阶段后导入当前账号；保留原文资源及依赖说明，按需匹配，不新增执行权限或自动启动研究。

- 完整中英文界面覆盖各页面及弹窗，语言切换保留草稿／筛选／研究状态，原资料和用户内容保持原文。
- 四套全站配色、对应生成背景与独立黑色蒙版，保存主题选择；中英文首页标题切换。
- 多行研究输入、少量中文选择与当前摘要；创建和重新研究共享可读配置，详细能力按需展开，取消／应用保持一致，保留已有参数能力。
- 内部资料库和 Skills 采用先浏览、搜索与筛选的集合页面，新增／导入／阅读／编辑进入独立窗口；普通操作不要求内部编号或原始配置。
- 实际 DAG 流程画布融入 SSE 实时反馈；上层自绘机器人以真实状态显示表情，下层角色工作区包含动作、结果和可展开历史，工具保持工具身份；支持缩放、平移、定位、跟随及动作详情，完整列表进入研究记录。
- 独立技术窗口，以全景、Agent执行循环及八个专题的细图解释研究、取证、RAG、Skill、路由、执行边界和交付；展开Host／Runtime／角色归属、数据与控制及返回路径，节点提供输入输出和实现位置，支持原理演示、暂停和单步。
- 阅读区采用简洁正文、章节导航、证据卡片和图表操作；运行信息进入独立记录。
- 根据 Beautiful UI 与 Bencho 的已选非侧边栏组件自行适配交互，统一文字、焦点、状态、移动端和减少动效。

## Capabilities

### New Capabilities

- `research-workspace-presentation`：主题、标题、配置、运行图、技术文档及证据阅读的前端呈现契约。

### Modified Capabilities

用户追加任务暂停／继续入口：沿用权限及原预算，增加在图步骤检查点协作暂停和继续的契约，不修改 Agent 分工。

用户后续追加系统主动诊断与分类修复：沿用原根、原期限及资料权限，分析按实际故障类型分配不同恢复次数，先修正请求结构／上下文再请求；报告按具体主张多轮修改及重新核对，以进展和额度共同限制。动作保留在工作区与研究记录，未增加自治Agent或代码自修改权限。

## Impact

2026-10-26追加：45项研究方法改为仓库／镜像随附默认内容，各账号首次使用独立初始化，保留个人修改与停用／删除。报告样例导入先完成格式与内容隔离、模板数据契约及交互的设计，解析器与呈现扩展另列未完成任务；本轮不启动调研。默认方法仅以当前新增行为的最小用例记录RED/GREEN，不执行既有回归或探针。

范围为 React 前端、静态素材、任务暂停／继续 API、既有图检查点、分类恢复／报告修订、SSE 投递及 README/TODO。沿用 React、Tailwind 和现有运行栈，无新增关键依赖。沿用本地单写者和当前任务分支；后台全量调研目标仍暂停。不启动新的付费调研，不新增或运行回归、构建、类型、lint、导入或浅层探针检查；记录真实界面操作和源码审阅，缺少的完整业务证据保持待完成。
