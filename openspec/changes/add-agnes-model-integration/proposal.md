# Proposal

## Why

用户要求将Agnes加入ADRS可选模型，并授权本机开发时将简单代码任务委派给Agnes。现有OpenAI兼容客户端可复用，但提供方枚举不接受Agnes，也没有有界开发委派入口。

## What Changes

- 加入中国站Agnes提供方、官方端点和文本模型选择，沿用本人配置加密、预算和原模型路由。
- 加入本机开发委派CLI：只发送显式选择的源码及任务，限定时间、输入、输出和调用次数；返回候选修改与依据，由主执行者审阅应用。
- 使用本机受保护凭据，不将密钥写入仓库、命令参数、日志或任务产物；不自动改变正在执行的研究模型。
- 保存一次真实简单代码任务的调用与审阅记录；原研究报告结构故障继续独立跟踪。

## Capabilities

### New Capabilities

- `agnes-model-integration`: Agnes模型选择、本人凭据与有界开发委派。

### Modified Capabilities

无主规格变更。

## Impact

修改提供方配置、端点目录、模型设置目录、双语文案、环境示例及开发脚本／说明。复用OpenAI SDK和标准库，不增加依赖、Agent框架或常驻服务。真实凭据待控制台创建与本人配置后使用，源码接入不等于实际调用通过。
