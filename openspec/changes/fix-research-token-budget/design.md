# Design

2026-10-24云端接续A7：脱敏汇总只有累计用量和判定数量，不能证明单一根因。源码可确定的缺口是最多三来源的默认选段，以及仅按完全相同excerpt_id去重而未共享重叠原文。审核显式选择本项全部引用来源，仍用原窗口；按每份来源所有选段的起止边界拆成共享片段，每项局部passage以有序片段引用完整恢复自身原选段，不扩大其可用原文。每批由最早剩余主张开始，优先装入共享最多的项目，仍至多十项／22000字符，并经原请求预占准入。输出可给多个passage_numbers，代码逐个导出并校验原文锚点；任一非法编号或锚点使该判定不可确认，不接受模型自报引语／偏移替代。契约升为v3，旧v2判定不复用，旧结果不重算。此为减少重复载荷的实现，不宣称节省比例、条件语义完整或A7已经恢复。无新模型、Agent、工具、观察器或独立缓存；所有判定仍同根计费，原暂停保留。

唯一内容修订轮也复用相同原文共享函数，问题许可从原excerpt_id转换成服务端passage编号；每个问题仍只可使用自身许可片段，方法依据只携带原审核允许的冻结根记录，不能用作科学事实。原每批至多8段／6000字节原文的上界保留，另根据包括问题／全部引用原文的实际消息预占拆分未派发批次；拆分不重试已处理段落、不产生第二轮。任何必要段落失败继续保留原稿、原审与已收到的响应，只有全部修订并经原装配和整稿重审后才可能交付。没有为修订新增预算或自动观察任务。

2026-10-24成本／修订增量：已消费的审核预留按实际／在途扣用，实际时间区间取并集，释放只指未用部分，详见预算说明。一次内容修订不再因总段数超过12直接放弃，而在已验证模块总边界内按每批至多8段／6000字节原文逐批执行，每段一次；原限额／期限不足即保留原稿和已收到的修订响应。修订后仍覆盖整稿全部主张，输入完全相同的已支持判定可在该根唯一修订轮复用，变更／未支持项重新审核，旧模型／旧契约不混用；原文和方法锚点由代码复核，原费用不再记成新费。细节与未验证边界见[审核契约](../../../docs/report-evidence-semantics.md)。沿用A2AB-03／05／10基线v1.0的既有执行点，无跨任务缓存、新授权或预算扩张。

本次继续应用A2ABreak基线v1.0的[A2AB-03《上下文归属与跨租户隔离》](</C:/Users/wblxr/basic-memory/engineering/security/a2abreak/solutions/A2AB-03 上下文归属与跨租户隔离.md>)“工程解决方案”1—3：方法依据由已认证根的原始问题／冻结范围和本次证据构造，不接受网页／写作者自报method_id增加依据；仅在该段已具备服务端允许的method_id时接受相应模型判定。继续沿用[A2AB-10《委派环路检测与全链预算》](</C:/Users/wblxr/basic-memory/engineering/security/a2abreak/solutions/A2AB-10 委派环路检测与全链预算.md>)“工程解决方案”1／3：方法核对和论文核对共用同根预算、期限和有界修订，不另开模型额度。无新主体、跨组织委派、存储、Webhook或SSE通道，其他九项复用既有有效评估；模型语义结果不是权限控制或人工确认。完整合法资料旅程及U4边界仍待取证，不声称已通过安全验证。研究记录用schema_version=2分别显示原文／方法支持，历史v1不回算。

2026-10-24 A6审核误判增量：方法陈述与外部研究事实使用不同依据。Report及唯一修订后完整审核传入精确组装段落对应的kind（不可信提示）、原始研究问题／冻结范围／行动输入与本次材料覆盖；仅无引用gap可提出任务方法依据，仍由语义审核逐句核对并绑定已提供的method_id。科学结果、测量、人物／机构关系不得由任务输入替代。事实前提须被原文支持，建议不要求论文作者为其背书。模型遗漏判定／非法依据仍保持未核实，纯缺口文本不构成研究交付；方法和来源支持数量分开保存。A6原判保留，此实现须后续完整新研究取证。

2026-10-24增量：四次真实长调研在原900秒或上下文准入处暂停，尚未交付完整报告。仅新建长任务使用预算策略2：240000 Token／2700秒，报告预留24000、审核预留60000及480秒，仍包含在单一根内。版本／预留写入原预算JSON，已有短／中限额不变；历史无版本根采用原根限额及原12000上限／20%公式，恢复不继承新配置。取证次数与已知费用配置上限不扩大，未知费用仍独立标识。修改配置不等于验收通过，实际记录见docs/acceptance/unified-research-20261023.md。

## Context

根图只在工具调度处检查总量，分析/反思/报告直接外发。Report在写完后才从余量扣审核预算，且流式usage被忽略；审核的跨语言查询先扣最大额度且没有真实结算。最终用量合并后未重算停止状态。现有Python/React与JSONB继续使用。

## Goals / Non-Goals

修复当前主流程模型请求的准入、预留、结算与结束状态；保留报告正文和研究记录分离。此轮不实现分布式任务队列、外部Agent内部账单观测或新增Tokenizer/数据库，不自动重新运行完整调研。

## Decisions

1. 用普通任务内TokenBudget对象包围实际chat请求；根图给各阶段派生剩余额度，不在模型提示词中执行预算。请求前按文本UTF-8字节及封装余量保守预占输入、按供应商max_tokens限制输出。该数值是保守准入值，不宣称未知供应商精确分词；实际usage优先结算，缺失/失败/断流保留预占并停止不明余额的重复消耗。
2. 初始总量预留20%给最终语义审核、20%给报告（各有上限）。前序阶段及重规划只能消费其余部分；报告不能动用审核份额。报告/前序请求超时早于最终审核截止时间，保证审核时间份额。额度不足暂停或跳过可选反思进入最后交付；不通过重新规划重置总量。
3. 主/备每个实际尝试单独准入；受控请求禁用SDK内部自动重试。流式尾部usage进入账本；结束/异常均关闭流。usage超出预占如实记录并阻止后续，不裁剪真实用量伪造守约。
4. 最终审核优先直接在已保留的原文片段做语义判断，跨语言检索作为有限补充；按可用额度缩小审核批次，不因五条批次装不下就全部跳过。预算/时间不足的未核项保持not_checked，任务转为需要处理的预算暂停，原文仍保留。
5. 根预算汇总模型各阶段账本及工具Token，避免max(model,tool)漏计；用量更新后重新计算停止原因。未知价格独立标识，不将0当作已知免费。历史84,190/60,000记录不修改。
6. 报告质量另以“判断问题→所需证据→比较维度→结论与行动”组织。样例两篇摘要不足以交付高校研究布局、年度演进或合作建议全集；后续采用明确焦点、全文与相关工作、作者/团队来源及条件比较。没有新增材料时不重复包装六页，更不添加数量图凑信息密度。

## Security applicability

采用[A2AB-10《委派环路检测与全链预算》](memory://main/engineering/security/a2abreak/solutions/a2-ab-10-委派环路检测与全链预算)/基线v1.0/“工程解决方案”1、3项及“验收办法”T3的当前预算分支。执行点为根预算派生及实际LLM请求外发。既有11项评估沿用：无新A2A主体、凭据、Webhook或跨租户存储，本次不新增其他信任边界。仅执行本次预算消费者行为，不运行其他安全/能力回归；方案是待项目验证的工程建议，不能声称全部安全验收。

## Risks / Trade-offs

- 保守预占会比真实分词更早停止 → 展示预占与真实usage差别，精确Tokenizer作为将来可选适配；保留证据并明确暂停原因。
- 不明失败可能实际未收费 → 保留预占保证后续有限消费，不将未知记0。
- 单机阶段账本不提供跨进程exactly-once → 沿用原执行身份及持久化恢复，未实施分布式计费保证。
- 正文预算更少 → 聚焦问题和精简输入，不能以少核事实或虚构报告弥补。
