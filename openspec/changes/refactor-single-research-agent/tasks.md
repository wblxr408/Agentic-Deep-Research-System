## 2. AI判断研究质量与核验影响

- [ ] 2.1 在原分析／读者判断中识别关键答案及其事实前提；AI可提升次要数字／条件的重要性。返工当前全局回退：只复核受影响问题／结论，必要时补读、收缩结论或保留不确定性；没有明确全局影响不重核整稿，不以完整形式化依赖图为前置。未核项不能标成supported。
- [ ] 2.2 保留常规阅读同次判断，AI结合命题、用途和实际后果给出问题等级、依据、位置及修复建议；允许非阻塞建议。三个分析维度用于解释，不硬编码成唯一阻塞公式；只有关键争议值得再判断时才复核，明确的正常复现或不同边界不重复审计。
- [ ] 2.3 沿已有事实／推断／建议／方法审核合同补差；AI依据来源和任务判断前提及外推，不要求论文事先提出本报告的新课题。旧负判是诊断，可据新证据纠正；确认的核心错误须修正或明确保留缺口，不能靠改标签放行。
- [ ] 2.4 正文、附录、图表及解说共享当前有效主张／范围；相同事实复用，新增解说／数值／视觉推断单独判断。复核由实质冲突、影响和收益触发，原根累计机会仍生效；当前同输入已判断的争议不因换阶段重来。不能用达到次数上限证明研究已充分。

## 3. 内容归属与增量修订

- [ ] 3.1 沿现有RAG目录、技术卡及阅读计划保存逐篇层级／缺口；AI根据问题调整阅读深度、主题和必需字段，允许有据再分类。用户明确全部阅读／指定字段不能自行取消，系统推定要求可说明理由后调整；摘要不算精读、未处理成员不能消失。
- [ ] 3.2 保留已有章节有界输入和前章全文去除；在现有Analyst综合／写作调用中形成问题—结论—章节归属及必要源材料，避免再开同材料规划调用。章节职责是可调整的研究计划，仍须覆盖用户所选问题；来源条件／反例不能被摘要替代。
- [ ] 3.3 保留稳定段落ID、内容版本、位置及修订记录用于定位；仅保存实际需要的前提／指代／条件关系。AI判断含义和影响，ID／相同文字不证明语义一致；不强制为所有句子构建完整图，也不以整稿版本变化自动清空全部审核。
- [ ] 3.4 沿现有编辑／修订入口，由AI选择删句、移动、合并或定向替换，代码核期望版本、字面操作及引用。混合段只修相关部分，保留独有机制／条件。旧版本补丁拒绝，必要的正文结构变化才扩大编辑范围；不要以整篇重写回避局部操作。
- [ ] 3.5 先复用已有事实审核、来源资产和响应缓存，重做未提交候选中的过宽失效。程序核当前来源／权限／合同，AI判断相关变化的语义影响；采集时间、估算Token或无关段落变化不直接使所有正判失效。跨版本不能直接套旧正判，有据完成影响复核后重绑当前依赖；正文复制到图文不能无故重审相同事实。不建独立缓存管理器／通用语义缓存平台。
- [ ] 3.6 保留已实现读者材料／覆盖／长附录分包，组合当前有效维度；AI判断局部或全局影响，条件／唯一答案／主要结构变化扩大相应范围。仅必要当前输入变化的包重审；不每次重新全文阅读，不把旧整稿通过直接贴到新稿。
