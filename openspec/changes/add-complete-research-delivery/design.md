# Design

## 2026-10-25：审核原文位置与建议校准目标

冻结实际U2d为失败基线：最终claim32的解码Lm最大批大小原文在保留PDF约41551位置，claim47的rank=8在dLoRA实验设置，当前却取摘要／理论背景；完整正文仍在，不是聚合丢失。跨阶段retain_technical已经按已通过字段保留，并非后阶段覆盖。实际摘要有未被所列proof覆盖的数值，原校验拒收字段是合理边界，但这些摘要的原文字面引用仍能作为位置线索。

报告生成接收本根已保存analysis_workflow，普通函数仅对当前来源ID和同规范源URL的当前正文重新定位原始technical_cards引用，保留合法位置；已通过技术卡的原offset仍复核。可容忍ASCII词的PDF行末断字作检索定位，实际摘录与审核锚点始终使用当前原文字符。模型摘要未通过不因此升级，未知ID、发现片段、未知字段或找不到的引文不成为线索。阶段记录另存技术字段status／reason，正文不带诊断标签。

检索保留每个引用来源和原双窗口／原预算：补充参数词和最大批／解码等本地检索词，完整技术标识辅助定位，不新增翻译模型。技术生成用短引导代替重复长叙述，字段细节必须由其quotes覆盖。v6审核仍用原事实／推断／建议／方法三字段正判及字符锚点；明确开放研究问题是拟议研究工作，不等于保证组合可行；原稿件报告的结果可作来源归因，不需要字面“self-report”标签，也不证明独立复现。缺证测量、资源／效果保证和全文不存在的断言仍拒，v5正判不复用。效用、完整报告及全部原能力／安全条件由后续完整旅程验证，禁止局部检查。

## 2026-10-25：完整对象尾部单个冗余右括号

U2d实际完整7850字符响应在7849处被标准JSON解码器以Extra data拒绝，余串仅为单个右括号，造成同阶段付费重做。Analyst保留标准解码优先；只有已strip／外层json fence后的标准Extra data位置到末尾恰为单个“}”、之前全体文字可解成完整dict时，恢复该原对象。字段和所有字符串值不改，原字面控制字符值保真路径保留；不寻找其他对象、不补内部结构、不接受第二对象或尾随文字。finish_reason=length仍先于解码停止，组织字段／analysis_text和全部原证明／阶段／额度校验继续。原始响应及格式恢复种类／cleaned offset写内部extraction记录，与控制字符修复计数分开，不进入报告正文。无额外模型、恢复次数或额度；完整旅程验证前仅记源码。

相同发表合并后保留每条真实source_url、署名和证据ID，模型临时output_id仍映射至该规范成果；期刊扩展／预印本的研究家族依旧需原有明确关系证明。同一规范来源的类型／日期冲突仍拒绝。每来源的采纳／全文状态保留；accepted_source_records计来源，accepted_publications计独立output_id，accepted_without_full_text仅计所有关联来源均未取得全文的发表。新声明版本启用新身份规则，旧v2继续URL口径；存量快照不改、不混用已完成阶段。没有新Agent、依赖、模型、抓取或权限。源码与完整图文的效果分记，不把旧4条改写成一次新的成功。

2026-10-24 FLOW.10必要种子缺口：Analyst原12000字节种子裁减会对深读本组的指定成果执行pop，仍可能返回非空分析并完成阶段。深读改用已有采纳身份投影：不重复携带完整署名列表，署名与证明留在原根；所有指定ID／题名／日期／来源URL与证据映射保持完整，不以删成果换准入。实际模型容量和原根预算／期限仍由完整消息准入处理，源选段与条件是否完整继续独立记录。非深读问题仍按有界完整记录选择，实际选中／遗漏及字节量写既有阶段context。增加问题种子契约版本进入分析绑定和工作流，旧契约直接调用在供应商前拒绝，不清空旧阶段／尝试；API恢复沿原绑定检查。无新Agent、框架、观察器或独立额度，旧失败保留，尚未运行统一旅程。

2026-10-24 FLOW.10.4源码衔接缺口：技术卡的字面proof先前只进入分析记录，写作者的原文窗口仍由通用词重新检索，无法利用已定位的条件附近文字。根Report入口现传入当前technical_reading，由普通函数将状态合格且当前保留文字／偏移一致的proof投影为同源位置线索，复用原相邻段落函数、选段配额和重叠合并，不增加模型或来源。定位窗口优先，原通用检索保留；逐proof实际选中／遗漏进入既有report_context而不进入写作诊断。原文变化／缺失的proof不作为线索；选择只证明输入文字范围，不证明科学支持。无新Agent、框架、网络、观察器或权限，恢复与原根额度／期限不变，4.5及统一端到端仍未通过。

## Context

见proposal.md。现有根图已经生成报告并保留引用/组织统计，但查询中声明的图像模板仍显示待渲染；前端仅展示Markdown。已有planning_control中的迭代决策尚未用于reflection路由。当前采用Python、TypeScript/React和已有依赖；技术栈评估不支持现在迁移Go/Rust。

## Goals / Non-Goals

**Goals:** 串通既有流程；提供无新模型调用的声明式交付视图、基础内置图表、明确缺口和稳定导出；任务计划与停止原因对用户可见。

**Non-Goals:** 不实施所有18模块的候选算法、独立常驻worker、分布式事件或任意代码绘图。报告原生PDF/PPTX、需要额外工具的Skill和未适配高级图型保留扩展状态。所选绘图Skill的声明式文件渲染已作为当前增量纳入，单图PDF与完整报告PDF分别表述。

## Decisions

1. 新增普通纯函数交付组装器，不增加Agent、框架、存储表或渲染服务。API在读取已鉴权的冻结结果后组装，artifact_id由实际内容和版本确定；副作用为零。以后预计算存储可保持同一契约。
2. 使用正文二级标题作为页面内容定位。自定义标题先精确匹配；否则按显式模块匹配固定章节词典。模型生成时接收声明式页面要求，但不会把匹配到段落等同已回答页面问题；未精确匹配显示缺口并保留全文。
3. 统计图只使用现有statistics.series/object_rows及metric_registry；关系图只用已保存关系的实体、边和proofs；通用任务可以展示取证来源分布，明确单位是citation。服务端不从模型正文重新抽数值。
4. 交付数据与UI分离。UI使用React转义、SVG和原生details，图型支持条形/折线/关系网络/时间线及表格；复杂图型缺少数据时列缺口。JSON保留完整数据，HTML克隆实际呈现并去除应用专属控件，补离线目录/全部页面静态显示/打印样式。
5. Skill执行经受信适配器，不能通过读取Skill就执行任意本地代码。手选／自动方案冻结适用render阶段的注册指令，Report模型只输出允许图型和样式参数；固定Matplotlib程序使用冻结数据产生SVG／PNG／图表PDF。未适配或失败显式blocked，不把内置渲染标成所选Skill产物。任务／execution／描述／数据／Skill身份匹配后才供交付读取，读取本身不重新调用模型或渲染。
6. 根reflection产生iteration_control并持久化，路由读取其action；保留旧任务默认兼容。计划清单与实际DAG状态分别显示，避免把初始pending清单冒充实时状态。计划策略与并发配置进入原请求快照。
7. 报告与研究记录分别呈现。正文生成器保留段落kind、统计绑定及审核的结构化记录，但不把它们转为段落标签、状态警示或技术附录。报告视图只显示内容、自然语言图注、单位、数据和文献引用；artifact_id/snapshot_id/metric_id仍保留在API/JSON及应用专属研究记录中。HTML/打印移除研究记录，Markdown导出使用同一阅读正文。历史报告仅按旧程序明确生成的章节/前缀作兼容投影，不全局删除包含“未知”“限制”等词的研究论述。本次样例按保留来源人工编辑，旧稿及旧审核另存，不能将编辑冒充重新取证或审核通过。

## Risks / Trade-offs

### 自动上下文与通用阅读结构实现增量

采用普通`research_context`函数按来源选取方法、实验、身份和条件段落，保留原证据引用号、字符/页码和遗漏；预算不足时保留较少来源的实质段落，不用几字符的窗口冒充全部覆盖。根据最终消息的UTF-8可信上界及既有阶段额度装配，结算/审核预留仍由原`ModelTokenBudget`拥有。来源全文可用、图表结构上限、模型实际选段和结论覆盖分别记录。

PDF正文使用原生文字流，结构提取上限另记；原始NUL使用可见投影和可恢复编码，使真实JSONB写入可完成。报告概要、主文与附录共用可信引用/统计/转义组装器；预设先展示核心判断，支持附录展开和主文/附录分别导出。技术对照表只读取已有定位字段，不猜性能数值。审核通过共享摘录表减少重复内容，仍限制每项主张可用来源并校验原文位置。

当前七项消费者行为已对各自失败完成修复验证；真实运行及语义质量独立记录。首次自动尝试已解决分析截断和报告无法派发，但最终审核仍暂停；后续原生PDF尝试发现NUL落库失败并已修复。未把两次记录改成完成。详细契约和适用性见`docs/research-context-packing.md`，真实验证不足时4.5继续保留未完成。

### 2026-10-22 全文研究与读者需求增量

主报告按研究问题而非逐篇论文顺序组织：开头说明重点判断及其合作含义，保留问题—机制—条件—行动的可追踪链条；逐篇全文表格和详细合作课题进入可展开技术附录，并支持单独打印。比较图使用同一条件下的明确数值或机制示意，不把跨论文最高倍数合成性能排名。当前北大报告以人工复核和整编完成；不能据此宣称通用自动模板已经具备该能力。

真实任务97b4ccc3取得13个来源后，分析输出达到长度上限、报告请求上下文预占失败，随后暂停落库因PostgreSQL参数$1推断冲突转为failed。当前最小修复：显式统一SQL状态参数类型；分析在finish_reason=length时保留用量及原始片段并返回暂停，不把截断JSON作为报告输入。沿用既有根预算/暂停边界，不新增Agent、额度或存储。自动上下文打包、逐子问题全文分析和通用主文/附录渲染仍为未完成任务。

- [章节匹配可能不满足自定义问题] → 精确匹配/模块匹配标识、明确未独立回答和完整正文；不自动制造新模型调用。
- [图表误解为现实全集] → 保留样本单位、未知年份、统计身份和来源；引用数量仅取证分布。
- [离线交互依赖应用状态] → 导出移除应用按钮，原生details、SVG、静态页面、目录及打印替代保留。
- [新增界面不解决旧正文支持缺口] → 审核结果在研究记录中保留，正文用来源归因、明确研究范围和有依据的结论表达；不附加成功审核标识，不把编辑改稿标为重新审核。

## Migration Plan

完整目标恢复后的4.5增量使用一个Analyst顺序执行“成果抽取→已选问题”，深读按成果分组，不新增Agent。以`analysis_workflow`保存阶段输入绑定、结果和尝试上限，当前owner/execution/计划下持久化阶段与原用量；工作区显示实际进度，原预算、期限和来源权限不变。用户同根恢复入口、迟到快照防倒退、缺少实验字段的有界补读与结果／条件整体装配已接源码，见`docs/question-analysis-workflow.md`。完整条件的语义覆盖和最后统一端到端仍待，当前不运行局部或构建门禁。

前置成果抽取进一步按取得全文与保留出版页显式链接分组，每次两个阅读组，原引用号不变。模型批次内ID在可信合并时隔离，仍按原规则校验题名、日期、署名和同成果依据。检查点采用v2，拒绝把旧单次抽取契约混入新阶段。该变化解决身份窗口与技术窗口争夺上下文的具体问题，不以分组代替成果身份核验，也没有重置原根预算。

绘图技术选择按tech-stack-evaluator处理，保留Python／React；内置浏览器SVG作为交互基线，Matplotlib补独立矢量／栅格文件，避免为首次文件交付增加浏览器渲染服务。接受包与字体部署成本；资源性能、实际可读性与兼容尚未实测。功能、开发／复用、生态／可靠性、部署／维护、安全、总成本和退出的适用边界及官方资料见`docs/research-figure-skills.md`。这不是14维打分或性能结论。

绘图执行只加载注册Skill内容到声明式模型上下文，固定子进程不接收凭据、Skill脚本或原始文件路径。一次计划与45秒／原截止时间中的较小渲染期限共享原根预算。复用A2ABreak v1.0 03/05/10，新增阶段重读01《技能声明验证与委派准入》方案1/3/4及08《结构化授权请求与权限不放大》方案1—4；控制点和待统一端到端场景见上述绘图ACI，未运行安全验证。

相同来源数据图在不同页面采用不同呈现时，每个“来源图ID＋呈现种类”有独立产物身份；同种类跨页复用，模型不得改来源数据。交付读取同时检查产物ID、来源图与呈现对应关系，避免后一个页面覆盖先前选择。矩阵保留表格的完整数据入口，不把缩略图代替完整实验条件。

增量字段兼容旧报告，依既有auth/result接口返回，无数据库迁移和新依赖。若回退前端仍可使用report/citations。保留完整TODO高级项和最终端到端待验收状态；所有本轮主要功能完成后再运行统一真实E2E。
## OPT-15 immutable text history and reusable layouts

现有PostgreSQL增加报告文本版本及声明式图文模板版本两表，不增服务或Agent。报告在原owner/execution事务后保存原文版本映射和审核，report_binding防旧稿混新资料；完整稿／草稿／中断响应分别呈现。模板独立于权重，owner范围内expected_version追加、request_id同参数重放，项目标签不授予共享权限。复制后实际配置进入当前预览及Skill准入。冻结writing_plan适配回答类型和深度，页面／模块结构优先。DDL仅接初始化及migrate入口、未运行；文本历史不复制图像文件，PPTX无适配时预览拒绝。控制点与最后场景见docs/report-history-templates.md。
