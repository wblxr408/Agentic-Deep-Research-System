# Spec Delta

## Purpose

让成员在明确加入的组织空间中分享自己选择的研究和资料，同时保留个人默认隔离以及对分享的撤回权。

## ADDED Requirements

### Requirement: 显式加入组织空间
系统 SHALL 允许用户创建空间并邀请指定账号；受邀人接受前不能读取空间内容，空间所有者可取消邀请或移除成员。

#### Scenario: 邀请与接受
- **WHEN** 活动账号收到并接受针对自己的有效邀请
- **THEN** 该账号成为空间成员并可读取授权分享

#### Scenario: 非成员访问
- **WHEN** 未加入或已移除的账号请求空间、成员或分享资源
- **THEN** 系统拒绝访问，管理员身份不自动授予成员资格

### Requirement: 本人资源显式分享
系统 SHALL 允许成员主动分享自己拥有的研究报告或资料供同空间成员只读查看，默认不共享个人密钥、模型配置或未选资源。

#### Scenario: 分享报告
- **WHEN** 成员选择本人可访问的研究报告分享到所属空间
- **THEN** 其他有效成员能够通过共享入口查看该报告，原个人访问规则不变

#### Scenario: 撤回或失去资格
- **WHEN** 资源拥有者撤回分享、资源不再可用或成员退出空间
- **THEN** 后续共享读取被拒绝，个人原资源不被删除或改写

### Requirement: 分享不扩大执行权限
系统 SHALL 将空间阅读与研究执行分开；空间成员不得仅凭分享读取拥有者私有来源、使用拥有者的模型凭据或更改原资源。

#### Scenario: 共享报告含私有来源
- **WHEN** 成员打开共享报告中的私人原文或执行动作
- **THEN** 系统仍按该成员各自的访问及执行许可处理，不能借用分享者身份
