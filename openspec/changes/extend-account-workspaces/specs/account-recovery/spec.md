# Spec Delta

## Purpose

为已有与新注册用户提供可选的本人邮箱验证和密码恢复，在不改变现有账号身份的前提下保护会话与个人资料。

## ADDED Requirements

### Requirement: 邮箱绑定需本人验证
系统 SHALL 允许已登录用户请求绑定邮箱，只有收到并完成一次性验证后才能用于恢复；现有用户名登录和未绑定邮箱账号继续可用。

#### Scenario: 邮箱待验证
- **WHEN** 用户提交新邮箱但尚未完成验证码验证
- **THEN** 系统保留原有效邮箱，新邮箱不能用于重置密码

#### Scenario: 完成验证
- **WHEN** 用户在有效期内使用属于本账号的一次性验证凭据
- **THEN** 系统将该邮箱绑定本人并使凭据失效

### Requirement: 密码找回与会话撤销
系统 SHALL 仅通过本人已验证邮箱提供有限期、单次使用的重置流程，并在成功修改密码时撤销该账号的既有会话和 API 凭据。

#### Scenario: 成功重置
- **WHEN** 用户提供有效重置凭据和符合现有密码规则的新密码
- **THEN** 系统原子更新密码、消费凭据、撤销原会话及 API 凭据，并要求重新登录

#### Scenario: 无效凭据
- **WHEN** 重置凭据已使用、过期、失效或不属于目标账号
- **THEN** 系统拒绝修改密码并保留原账号状态

### Requirement: 不暴露账号存在性
系统 SHALL 对找回请求使用一致的公开响应并限制请求频率；当邮件服务未配置或不可用时提供清楚的可恢复状态而不公开秘密。

#### Scenario: 不存在的邮箱
- **WHEN** 未登录访问者提交不存在或未验证的邮箱
- **THEN** 接口不揭示该邮箱是否属于某个账号
