# Spec Delta

## Purpose

让用户以自己明确提供的外部授权访问受支持的研究平台，凭据和实际调用仅属于该用户并可随时撤销。

## ADDED Requirements

### Requirement: 个人凭据的保存与撤销
系统 SHALL 为每个账号独立保存受支持平台的凭据，列表仅返回连接状态和非敏感标识，支持替换及撤销。

#### Scenario: 不同用户独立授权
- **WHEN** 两个用户分别配置同一平台的凭据
- **THEN** 每人只能查看和使用本人的连接，配置读取不会返回原始凭据

#### Scenario: 撤销连接
- **WHEN** 用户撤销本人连接
- **THEN** 后续新请求不再使用该凭据，其他用户及宿主配置不受影响

### Requirement: 授权接口受限使用
系统 SHALL 在 GitHub 官方只读 API 的固定入口使用本人凭据，沿用原工具、来源、速率和根预算限制，禁止将凭据作为 URL、日志或跨域跳转数据。

#### Scenario: 自己的研究使用连接
- **WHEN** 用户在授权渠道执行受支持的只读 GitHub 请求
- **THEN** 仅该次请求使用其个人授权并按原任务账本计量

#### Scenario: 未授权或不支持的平台
- **WHEN** 用户未配置连接或选择尚未实现个人授权的平台
- **THEN** 系统展示实际可用状态，不能退回其他用户或宿主登录态
