# Proposal

## Why

OPT-04需要同一证据对象的明确特征视图。当前上传总是调用嵌入，但没有词项／统计／特征版本及实际模型配置记录，简单检索也依赖模型可用，费用和可解释性不足。

## What Changes

- 构建有界中英混合词项、原位置、词频、源内df／IDF等特征，区分词汇稀疏与学习稀疏；实体及时间只在有依据时链接。
- 上传显式选择是否保留稠密表示，默认使用无需模型的词汇视图；选择稠密时记录实际模型、版本可用性、维度、归一化及编码边界，失败不提交不完整表示。
- 检索词汇路径与稠密模型解耦，旧片段不追认未知模型版本；特征详情／下载显示缺口及候选取舍。
- 细粒度、学习稀疏、行为及图文模型按当前数据／收益选择；未采用状态明确，BSR仍待具体定义，不把图注当图像编码或共现当关系。
- 代码实施后继续完整TODO，全部实现后统一端到端能力验收。

## Capabilities

### New Capabilities

- `versioned-retrieval-features`：同源版本的词汇、稠密、实体、模态与时间特征视图及选型可见性。

### Modified Capabilities

无主规范修改；沿用任务接入／解析／分块和认证边界。

## Impact

普通特征模块、上传策略与现有JSONB、嵌入器的实际编码元数据、RAG可选稠密路径、资料管理特征控件和详情。无新增Agent、推荐训练任务或模型服务，不自动采集用户行为。现有来源和历史报告不重写。
