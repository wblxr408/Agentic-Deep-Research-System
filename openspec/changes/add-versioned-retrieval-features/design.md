# Design

## Context

动机见[proposal](proposal.md)。OPT-03有规范原文和逻辑块；现有documents.embedding可空，但上传强制Embedder，RAG在全文查询之前依赖嵌入器。当前FTS使用ts_rank，不能称为完整BM25。没有用户偏好行为训练数据或可访问的原图编码输入。

## Goals / Non-Goals

**Goals:** 生成可解释的多视图数据并贯通显式接入、检索与详情；支持选择固定版本的学习稀疏、细粒度多向量和实际图文编码；减少无必要模型调用，保留后续索引的表示版本依据。

**Non-Goals:** 不把所有候选模型都接入，不训练推荐器，不把词频当LSR、词项位置当ColBERT或图注当CLIP，不自动向量化任务网上证据。

## Decisions

### 1. 有界混合词汇及源内统计

普通函数做Unicode NFKC／casefold，保留原词位置；英文／技术字面和中文字符／相邻二元组可选，最多2048词项事件／块，词长有界。默认不做词干化，避免RDMA、模型名等术语被错误折叠；不依赖新语言服务。保存TF、源内DF、平滑IDF及归一TF-IDF，明确N是本次来源索引小块且重叠块分别计数，后续跨来源查询须按实际候选全集重新计算。单来源增强JSON最多8MiB，超限省略且统计只覆盖保留视图，不标全集完整。

### 2. 稠密表示显式选择与身份

FeaturePolicy默认dense=false，上传不初始化Embedder；dense=true时继续现有SentenceTransformer.encode归一编码，不更换模型或默认下载另一个模型。记录配置模型／请求revision、可得实际commit、库版本、实际dim／max_seq_length及tokenizer输入超长范围；维度／finite校验失败回滚整次接入。新配置进入幂等key。RAG默认词汇且稠密／重排分别由服务器显式配置，模型故障不阻断词汇。向量仅在编码profile可兼容时参与，旧未知编码不猜。

### 3. 候选状态和模态依据

LSR／SPLADE／DeepImpact额外需要模型、词表和稀疏索引，当前保留not_selected；ColBERT式token矩阵及MaxSim需专用模型和索引，不能将已有单向量伪装为多向量。行为模型先核对授权数据：没有稳定曝光／点击序列与训练目标，因此不采用协同过滤／Item2Vec／行为双塔，不收集新行为。用户指定推荐仓库中的YoutubeDNN实际依赖user_id、article_id、expo_time和历史序列，不适配当前单次任务证据；只读参考不复制代码。BSR没有指定唯一体系，保留unresolved_definition，不擅自展开缩写。图像输入未保留时，选择文字／结构独立视图而不调用联合编码；以后用户授权原图和模型后再以收益／成本选型。

### 4. 实体与时间

复用03字典提及和原位置；词典链接不是身份确认。已有组织关系保留自己的来源／时间审核，不从词项共现创建事实边。用户可声明来源日期、as_of、半衰期和时间窗口；全部冻结到feature policy。声明非核实；未知不猜，未来日期返回未知而不负年龄加分。历史报告的趋势依据仍由组织趋势模块处理。

### 5. 存储、界面和ACI

来源metadata保存feature_plan和feature_profile，索引行只保存该块词项／实体／时间视图及实际编码profile；普通编辑保护这些字段。新GET sources/{id}/features只读展示／下载，旧来源unknown；接入策略面板展示成本选择与日期来源，批次沿用固定策略。后续OPT05负责索引构建／发布，不在特征读取时触发构建。

### 6. 边界与实施时序

复用A2ABreak v1.0全11评估及03／06／08／10“工程解决方案／验收办法”：实际owner查特征，版本／事务幂等，特征选择不扩大模型或出站权限，特征量／模型调用受既有任务预算。无新增Agent／A2A／回调／常驻训练任务，其余适用性不变，引用入口见[TODO](../../../docs/OPTIMIZATION_TODO.md#安全方案引用与规划状态)。所有新增控制待全部TODO实现后统一端到端；不运行逐项测试或门禁。

## Risks / Trade-offs

- [字面中文分词与技术术语语义不足] → 保存char／bigram策略和原位，质量未知；后续按实际召回缺口选分词器或模型。
- [词项与向量模型截断] → 分别保存各自覆盖，不能用字符块长推断token未超长。
- [默认关闭dense改变新上传成本／检索] → 控件明确选择，既有向量保留但未知编码不参与兼容新空间；词汇路径可用。
- [源内IDF误当全库分数] → scope／成员／重叠计数显式，不直接用于跨来源可比较结论。

## Migration Plan

现有JSONB／可空vector列支持，无重写历史来源。新接入独立feature版本，旧片段详情显示缺口；服务器稠密开关／模型revision配置默认关闭／空，不在本轮安装或启动。完成OPT04后顺序继续OPT05–18及跨模块，最后统一端到端。

## Open Questions

BSR所指具体体系待有明确定义／来源后重新选型；当前不影响其余特征契约，界面必须显示未解析状态。

## 7. 按完整 TODO 补齐可选模型特征（2026-10-27）

学习稀疏先支持SPLADE训练得到的Masked-LM权重：复用既有Transformers／PyTorch，本地固定版本、仅本地文件、显式选择；记录tokenizer词表、模型版本、实际输入长度、池化和保留的Top-K权重。用户未选择时不运行，未配置或截断不得伪装成功。细粒度采用实际token向量并为后续MaxSim保留模型、token位置与有效掩码；不能把普通词面位置或均值向量称为多向量。图文特征只处理本人主动提供且匹配源版本的原图／页面，使用同一已配置的兼容模型空间，文字和图像视图分别记录；当前04阶段先保证真实表示和来源绑定，05／11阶段再实现发布与检索，不把候选配置当可检索索引。

双塔只接受明确指定的配对编码模型及共同空间身份，不因维度相同就假定可比较。行为特征先核对实际可用、授权的曝光／点击／序列和目标；现有报告质量反馈不能冒充用户兴趣训练数据。BSR存在不同体系定义，保留待明确并继续不依赖它的实施。所有模型在显式许可、owner、原文／图片版本、调用资源及源生命周期范围内运行，旧报告不回写；代码及最终真实端到端分别跟踪。
