# Proposal

## Why

OPT-02要求取得可定位的正文、表格与图像依据，现有上传只拼纯文本，DOCX表格丢失，乱码会被忽略，PDF布局与扫描页缺口不可见。需要把原生抽取、可选OCR、清洗、重复候选及人工审核状态统一成可消费的数据。

## What Changes

- 为TXT／MD／JSON／DOCX／PDF及已取得HTML建立统一结构化解析输出，保留归一文本、块、源位置、表格单元格、图像／图注指针与质量状态。
- 修复DOCX字节签名；保留无文本页、截断、乱码和未知，原始抽取文字与清洗转换分别保存，不静默丢失字符。
- 原生解析优先；PDF布局与表格用有界解析器，扫描页可显式启用本机Tesseract。可由本人选择兼容多模态模型，对本人重新选择的原文件页面或嵌入图片执行有限视觉解析；未选择／失败保留缺口，不自动外发。
- 精确重复可复用，近似／语义相似只给候选，不自动合并论文或删除证据；提供可选模型清洗建议与语义比较、本人解析详情及版本绑定人工标记。
- 解析版本进入资料幂等与任务证据版本，图表引用不等于图像已理解或数值已核实。
- 按用户约定，全部TODO实施后统一端到端验收。

## Capabilities

### New Capabilities

- `structured-document-parsing`：有界解析、原文位置、结构化表格、图像指针、可选OCR、质量和人工审核。

### Modified Capabilities

无主规范修改；复用正在实施的任务证据接入及已有组织样本契约。

## Impact

统一现有上传与PDF读取入口，新增普通解析模块、原文结构详情和OCR配置；PDF布局依赖pdfplumber，复用已存在pypdf作明确降级。视觉／文本理解复用本人模型配置与独立有界操作，不新增Agent或自动读取图像URL；新的模型结果作为可追溯派生记录，不覆盖原文。OCR外部程序不自动安装或运行；通过显式选项及服务端配置启用。
