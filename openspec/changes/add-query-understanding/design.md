# Design

## Context
见proposal；组织配置与权重已可冻结。目标完整范围和最终端到端时序保持不变，当前不执行任何代码检查。

## Goals / Non-Goals
用普通模块扩展ResearchRequest，增加只读预览和主入口复算，在原JSONB及ResearchState保存；语义候选不是已核验事实。模板/绘图声明式描述先固定，完整渲染由OPT-15接续，不宣称已支持所有导出。保留Python，不据技术栈评估擅自迁移语言。

## Decisions
1. 规则/字典优先，现有Planner承接剩余语义分解。不新增分类器、NER权重、第二Agent或必选模型分析轮；未可靠识别的名称是候选而非伪造已链接实体。
2. 指代只使用当前显式对象及同owner显式历史配置的有界对象。可选ID必须属于这些候选；同名不同ID保留歧义。历史不带入权限、证据和完整会话。URL为查询线索，继续交给既有出站政策。
3. 用户可补目的、约束、实体、查询类型、时间和交付描述。解释ID覆盖有效配置、上下文实际版本及当前日期，不含每次变化的采集时间。创建复算并校验ID，未解决歧义409，输入无效422、上下文404；预览不写业务对象、不取证或调用模型，允许既有注册表读穿缓存。
4. 原问题保留，附加有界结构化契约提供给规划/综合/审核/报告；已冻结解释参与快照持久化和结果，恢复不重算。新增来源线索不自动扩大组织/来源范围；权限仍由可信工具边界执行。
5. 交付仅接受有界声明式字段，不接受脚本、任意文件路径、网页技能指令或工具权限；技能版本取实际注册表解析结果。模板渲染能力状态显式记录。

## Risks / Trade-offs
规则无法完整理解任意语言→保留未知与用户覆写，已有Planner负责语义推理；不伪造准确率。只读预览与创建间变化→复算标识，创建后冻结。预览无token费用仍有有界CPU/DB成本→限制文本/实体/页面及历史读取量。

## Security baseline
增量复用A2ABreak v1.0的全11项评估；03“上下文归属与跨租户隔离”、06“并发状态版本与审批绑定”、08“结构化授权请求与权限不放大”、10“委派环路检测与全链预算”、11“中断任务租约与有界资源回收”的“工程解决方案/验收办法”作用于显式owner上下文、解释版本、服务端技能/权限及原运行预算。04/05沿用原SSE/产物契约，01沿用注册准入；02/07/09未新增Card、Webhook或跨组织多跳，不扩大适用性。索引为Basic Memory main/engineering/security/a2abreak/a2-abreak-多-agent-安全基线与-11-项方案索引，条目完整评估复用既有实现记录。本地建议待最终E2E，非官方修复。

## Migration Plan
无新增DDL/依赖；新字段有默认值，旧请求继续可用，旧会话标legacy；新解释随已有JSONB快照保存。按全部实现后的统一真实端到端验证双owner、模糊指代、冲突日期、预览更新、目的/交付快照和恢复。
