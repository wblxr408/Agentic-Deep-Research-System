# Proposal

## Why
OPT-07需要在取证和模型调用前明确用户的问题、对象、时间、目的与交付要求。现有组织配置可冻结，但通用查询及显式续接上下文缺少统一解释与歧义交互。

## What Changes
- 规则优先形成五类查询、实体候选/链接、显式上下文指代、时间槽位、复杂度与成本依据；保留未知，不假装完成事实核验。
- 新增只读查询预览，在创建前复算并拒绝未解决歧义；提供补充约束、实体选择、时间和研究深度交互。
- 冻结任务/交付描述、真实组织/权重及技能版本，接入规划、分析、报告、恢复与结果；声明式模板配置不授予工具权限。

## Capabilities
### New Capabilities
- `query-understanding`: 查询解释、必要澄清与可恢复的任务及交付快照。
### Modified Capabilities
无。主spec当前为空，复用已有组织变更内的范围与配置契约。

## Impact
新增普通Python模块和React面板，扩展现有research API/state/节点，复用PostgreSQL JSONB；不新增Agent、依赖、队列或模型轮次。模板渲染由OPT-15完成。完整目标全部实施后统一端到端，当前不运行代码或任何检查。
