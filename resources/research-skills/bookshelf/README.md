# 研究方法书架

来自[用户书架](https://bo-skill-bookshelf.vercel.app/)的45项 ADRS 适配方法，来源版本和全部目录筛选见 [manifest.json](manifest.json)。

每个 Markdown 可通过研究工作区的“导入文件”写入本人方法目录。文件保留规范元数据、阶段方法、内部约束、固定来源和原依赖；本机个人导入副本在长度允许时以归档引用保留原主要 SKILL 文本，未声明为阶段加载引用；仓库只分发本项目的阶段适配文字，原始内容通过固定来源取得。原包与完整配套资源在本机 `.codex-homework/bookshelf/packages/` 保存。

运行沿用原 top-k、阶段字符预算、权限和工具。正文及 Stage 段进入对应阶段，归档引用不自动加载。方法／模板资源入库不代表脚本、宿主插件、R／GeoPandas 等计算环境或 PPTX／DOCX 导出器已接入。报告结构方法沿用当前报告输出，绘图方法使用现有受控渲染器。

适配方法由本项目编写；原文和原资源署名及许可仍属各来源，见各条引用。
