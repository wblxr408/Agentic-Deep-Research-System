# 研究目的与模块 ACI

组织研究的内容选择使用 `adrs-analysis-modules-v1`，目的字段自 `adrs-organization-run-v3` 引入，当前 v4 另外冻结[样本声明](organization-corpus.md)。目的回答“本次研究要解决什么问题”，模块限定叙述章节；匹配权重表达候选偏好，报告模板决定呈现形式，分别保存。当前交付不包含图像模板编辑器或绘图 Skill 适配。

## 输入与推荐模块

登录后读取 `GET /api/v1/research/analysis/catalog`，返回三个目的、模块说明、各目的推荐模块及规则版本。目录只读，不取证、不调用模型、不改变权限。`POST /api/v1/research` 的 `organization_research` 新增：

| 字段 | 合法值和默认 |
| --- | --- |
| `purpose` | `research_development`（缺省，布局与演进）、`cooperation_discovery`（合作发现）、`comprehensive`（综合研究） |
| `modules` | 1–6 个不同模块 ID；省略或 null 使用目的推荐值，显式空数组、重复、未知值拒绝 |

| 模块 ID | 问题 | 布局与演进推荐 | 合作发现推荐 | 综合研究推荐 |
| --- | --- | --- | --- | --- |
| `landscape` | 当前取得样本的公开研究全景与边界 | 是 | 是 | 是 |
| `evolution` | 可观察演进、覆盖变化与不能确认的趋势 | 是 | — | 是 |
| `relationships` | 已知署名、共著与其他关系的不同含义 | — | 是 | 是 |
| `deep_dive` | 已取得原文支持的成果解释与缺口 | — | — | 是 |
| `validation` | 支持、冲突、尚未取得的交叉材料 | 是 | 是 | 是 |
| `actions` | 后续研究验证问题或有条件的合作评估 | — | 是 | 是 |

任一目的可自定义非空子集，不强制企业参与。例如高校单选、`purpose=research_development`、`modules=["evolution"]`、合作发现权重预设可以同时成立，权重非零不会自动添加合作页。界面切换目的会采用相应推荐模块，随后可逐项调整；显式清空时拒绝提交，不自动恢复。

## 实际执行和结果

沿用原有 Planner、Analyst、Report 调用，没有新增 Agent、服务、数据表或额外写作轮次。Planner 和 Analyst 使用固定模块说明约束问题；证据抽取继续保留基础元数据。Report 同一次模型调用返回 `title`、`modules[].module_id`、`paragraphs[]`；段落包含普通文本、`observation`／`interpretation`／`gap` 类型及整数引用数组。

服务端普通函数只按冻结的已选 ID 组装章节，转义段落中的 Markdown／HTML 结构，由程序追加来源编号。额外、重复、缺失或无效模块产生 `issues`；来源摘述缺引用或越界引用不纳入。没有可用段落时保留模块和缺口，不回退到完整企业报告。返回 `draft_requires_review` 只说明结构和来源编号可消费，不证明语义已审核。模块原始内容、问题和 `independent_semantic_review=false` 存于 `organization_result.module_report`，现有最终主张审计继续针对组装后的正文执行。

JSON 生成阶段缓冲内容，组装后才发正文事件，避免把半段 JSON 展示为报告；前端仍可见原有步骤状态。模型断流沿用原可恢复失败，不在已有输出后自动切另一个模型拼接。没有证据时不增加模型调用，返回已选模块的不可用状态和证据缺口。

原有确定性样本与配置附录保留，未选 `actions` 时不再追加旧版模型建议。报告摘要的 `analysis` 保存目的、模块、名称、规则和未选项；页面、Markdown、JSON 及复用页面的离线 HTML 采用同一保存数据。结果页明确发起新研究时继续携带原目的／模块；只读重排仍只改偏好，不修改原报告。旧 v2 运行没有新字段时不按今天的默认值补写历史报告。

## 运行边界、错误及限制

请求沿用认证、owner 保存／读取、现有渠道、技能选择、工具网关和时间／token／调用预算。目的目录不授予工具权限；模型段落、用户名称和来源内容不能更改模块或权限。字段非法返回 422，界面空选择在发出请求前提示。模型结构失败记录问题及不可用模块；用户可据此补充材料或显式新研究，不隐藏失败，也不自动扩大来源。调用价格和审核状态仍按实际记录解释。

本项只接通问题、内容选择和基础报告契约。完整候选／采纳／排除／全文状态、学科分类、带时间关系视图、机制深读、趋势反证、可执行行动卡及跨图文统计分别按 7.2–7.8 实现。模块名称出现不等于这些深层结构化能力已经交付；仅单年度来源时也不能制造趋势。
