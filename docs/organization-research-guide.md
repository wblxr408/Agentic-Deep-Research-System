# 组织研究使用与当前能力

更新于 2026-10-21。当前主应用已接入组织范围、样本归属、评价／偏好预览、固定证据重排、目的／模块选择和报告导出。这里只描述实际交付和限制；完整图像模板、结构化深读、趋势和行动能力仍按 [TODO](OPTIMIZATION_TODO.md)与 [OpenSpec 任务](../openspec/changes/add-organization-research-matching/tasks.md)推进。

## 创建研究

登录后进入“研究”，启用“组织研究模式”。选择高校、科研实验室、企业中的一种或多种，填写一个或多个具体对象、所属类型、来源网址、学科及起止日期。高校和实验室可以独立成为对象，混合选择不要求对象之间已有合作。空类型、对象类型冲突和非法日期会拒绝提交。

对象来源网址用于识别和种子取证，**不会自动成为全研究白名单**。可另启用“声明样本与来源范围”，选择只读种子或检索加种子，填写域名、种子、检索式及成果类型；明确限定后由受控读取与结果过滤执行，不能自行扩大域名。当前限定来源使用网页传输，其他平台组合会拒绝。API 可组合五类学术／机构来源；界面先提供出版商与机构域名配置。见[样本／来源 ACI](organization-corpus.md)。实际覆盖仍不是现实全集；内部资料由独立开关按需补充，默认关闭。

“学科”保留请求标签；材料论文等已有真实期刊场景，但尚未逐篇自动核定学科、技术路线或多标签。实体初始可能为待消歧，不会因输入官网或模型提及就自动成为已确认对象。

## 配置偏好与评价

在对象范围之外，选择“布局与演进”“合作发现”或“综合研究”。切换目的采用推荐模块，可逐项增减；至少选择一个。研究目的、模块、权重分别保存：例如只研究高校演进，同时保留合作权重也不会自动生成合作分析页。当前模块控制问题和基本报告章节，完整机制深读／趋势／行动卡仍在后续任务中。见[目的与模块说明](organization-analysis-modules.md)。

选择研究发展／合作发现预设、自定义，或本人保存的方案版本。编辑主维度、成果表现组内及指标组内权重，可启停、恢复；页面显示归一化后的实际比例，例如 6:4 为 60%:40%。非法或校验中的配置不能发起研究。个人方案历史按 owner 保存，修改方案不改写旧研究。

权重预设是产品偏好，尚未业务标定，不能当作学术体系官方换算或合作成功率。评价适用性和指定载体／论文目录查询是独立预览：先选真实成果类型，再看各体系的适用性、版本、来源和缺失状态。查询命中部分公开目录，不代表已经自动给本次研究成果赋等级。

| 当前来源能力 | 已有实际内容 | 保留限制 |
| --- | --- | --- |
| CCF | 2012、2022 小样本目录 | 非完整目录；精确载体和轨道匹配，不把 workshop 当主会 |
| ICORE／CORE 历史 | CORE2023、ICORE2026 小样本 | 不同版本独立保留，不以名称近似套级 |
| ABDC | 2010、2013、2016、2019、2022、2025 少量样本 | 仅公开抽样载体，不是全部商科期刊 |
| OpenAlex FWCI／引用百分位 | 一个真实工作快照及原始 JSON 归一化接口 | 提供方特定字段；没有当前成果的自动实时查询，不生成 CNCI 替代值 |
| WoS／Scopus 收录、JCR、期刊分区表、CiteScore、SJR、SNIP、CNCI | 版本化记录适配与显式授权导入契约 | 尚无本机真实授权实时数据；无数据、未收录、不适用分别表达 |
| AJG | 独立等级及版本适配、授权导入契约 | 当前公开样本和登录授权资料缺口仍保留 |

实际快照在 `config/evaluation/public-snapshots.json`，明细、来源和授权语义以 [评价 ACI](research-evaluation-and-weights.md) 为准。注册了适配器不等于连通了提供方，也不代表已获得商业数据许可。

## 阅读过程与结果

报告中的“样本基线与流转”分别显示候选、采纳、排除、待核和全文缺口，可查看声明、真实执行式及具体来源行。月精度区间与请求部分交叠时保持待核，不把月初当实际发表日。来源网页和片段不计作论文，未取得全文不能声称机制深读完成。

工作台显示计划、执行步骤和工具结果。参数错误、预算耗尽或来源不足会留下记录；完成状态表示流程交付了结果，**不保证正文所有主张已通过审核**。如报告审计为待复核、来源支持不足或未检查，按该状态解释。

成果表区分发表记录和研究家族。同一成果可分别归属多个选中对象，汇总取并集，不把各对象行简单相加。没有版本关联证据时按独立发表单元，不凭标题相似合并。发表时署名、当前任职、共著、资助及正式协议含义不同；缺少已纳入关系不表示现实中不存在该关系。

日期只保留来源支持的日／月／年精度。已支持部分出版商 ISO／BibTeX 及明确 Published 标签的英文日期；新增英文路径只识别明确发表标签，不把 Received／Accepted 当作该标签。字面原文核验仍不代替独立语义复核；其他语言、格式或冲突保持待核，不保证所有网站均可解析。

## 固定证据重排

完成研究后，在结果页“固定证据重排”准备本次快照，编辑偏好后点击“重排当前证据”。这两个动作消费本人已保存的成果、原文位置和采集时间，不读取新网页，不修改原报告或原配置。

当前自动分项是标题词面重合和有界发表时效，其他路线／完整度／合作／未取得评价保持未知。未知项保留预算区间，显示覆盖率；关闭未知分项可以缩小区间，不能解释为补齐了原本缺失的事实。日期精度也会造成区间，因此覆盖率 100% 不一定有确定总分。共享同一论文的多个对象可能同分，不制造排名。

只有“重新取证并研究”会根据当前偏好创建新的有界研究及报告，继续携带原目的／模块、渠道、资料选择、技能和预算参数，并重新经过原授权／审批边界。见 [重排 ACI](research-reranking.md)。

## 下载与历史

报告中展开“研究口径”，可查看对象、原始／生效权重、版本、实际来源和未知项。下载 Markdown 为保存正文；研究数据 JSON 包含完整组织配置、结果和来源；HTML 复用预览内容、内联样式，原生折叠可离线展开。下载不调用模型，不自动发布或发起联系。

旧报告没有保存的新摘要不会用今天默认值补造。当前 HTML 尚不提供完整图像资产打包、自定义图像模板或绘图 Skill 切换；这些按后续 TODO 实现。详见 [报告导出 ACI](organization-report-export.md)。

## 学科分类与历史版本

工作台的“学科分类规则”可选择随学科的默认方案或自定义问题／方法／应用节点，填写独立版本；节点可有核心／关联、多标签与父级。新报告冻结当时规则。结果页“同证据学科重分类”使用本人已采纳成果与原文，保存新版本、选择历史及下载当前分类数据，不新增取证或模型，也不回写原报告。报告 JSON 保存首次口径和已提交的独立历史。

标题及明确标记的出版商摘要提供词面依据；未知不当作零值，旧材料缺摘要标记时不能凭空补齐。年度表仅显示已覆盖样本；重新划分标签不能解释为成果或投入增长。规则和错误处理见[ACI](organization-taxonomy.md)，实际材料学、权限与下载记录见[端到端记录](acceptance/organization-taxonomy-20261021.md)。
