# 分通道候选与原始依据

对应OPT-11。**源码已接入，未运行SQL、检索、模型或任何检查；全部TODO实现后统一端到端。** 继续使用RAGAgent作为显式启用的内部取证工具，普通查询函数提供候选，不新增自主Agent、图数据库或社区摘要服务。

## 可选模式与查询表示

`query_options.internal_retrieval_mode`可选hybrid或structured，并与原查询解释一起冻结。hybrid执行BM25、FTS、明确选择器和已配置稠密表示；本人可另选英文词形、学习稀疏、配对整体／细粒度语义或图文匹配，默认不运行。structured只根据业务筛选取当前合法块，按入库时间及ID确定次序，不编码、不使用相关性重排，也不将其顺序称为研究价值排名。内部资料未启用时不能暗中执行这两种路径。

明确选择器支持`chunk:<块UUID>`、`source:<来源UUID>`、`phrase:<完整短语>`（或完整引号短语）和`entity:<已登记词面实体ID>`。UUID在SQL前解析，短语是大小写不敏感的完整字面串；型号可作为明确短语查找。显式选择器保持指定匹配，不额外以通用词汇或模型查询扩张；entity／chunk仍可选择同源结构上下文。选择器不授予读取该ID的权限，其他owner／失效版本仍不可见。

FTS使用PostgreSQL词汇查询及既有词面词项，BM25使用当前范围的已发布词频，稠密查询只启用兼容的编码profile和精确距离。分通道原始排名／分数保留在`retrieval_routes`，包括channel、rank、raw_score、score_meaning、filter_id及候选上限；融合继续使用原RRF，原始不同分数不会直接相加。这些是相关性或结构匹配分数，不是事实支持率。

## 有界图辅助与层级

明确entity或chunk选择器可将合法命中作为种子，每次最多5个种子、一次同源同解析版本的父级／兄弟块扩展。返回块仍通过完整业务与可信范围过滤，并保留source_id、parse_version_id、parent_block_id及实际共享父级的种子ID。词面实体声明未做身份消歧；同一父块只是文档结构关系，不能当作署名、合作或任职关系。

原matched／parent／source_preference层级上下文路径继续适用，原匹配与扩展位置分别保存。这里实现的是小规模图辅助取证；GraphRAG社区摘要、已核实体多跳推理及广义GAG并非同一概念，也没有因为新增结构通道就变成已实现。没有对应研究需求、可信关系数据或版本化摘要时，不预设新图服务与训练。

## Beam Search Retrieval

本人可选“拓展关联资料”，使用实际检索命中的原始通道排名产生种子；仅在当前账号、资料分组／任务、有效生命周期、当前索引及业务条件的交集中遍历。每轮保留最多8个节点、最多2跳、每节点最多展开8条边，整次最多访问128条边并受原截止时间约束。边仅包括同一来源版本的共同父级结构，以及相同词典ID、类别和名称的原文词面提及；每个词面保留两端来源、字符位置和原文，核对位置后才形成路径。同名、共同提及或同一结构均不证明真实身份、合作、作者或隶属关系。

路径优先级由种子在原通道的最佳排名和候选原文对查询词的重合度计算，并随边和深度衰减；它是搜索顺序，不是事实置信度。完整路径保留每个来源、片段、代际、版本、原文坐标和边，界面执行记录显示路径类别；模型上下文只收到路径类别和“检索线索”的语义，不把路径两端的词面当作已核实结论。进入重排、返回和新的综合前，复核路径全部节点的权限、筛选、生命周期、代际和实际边；中途变化时不继续使用旧路径。明确指定单个来源或精确短语时不跨范围扩张，指定块或词面实体可使用用户明确选中的路径扩展。原任务策略冻结；模型训练、图数据库和新Agent不是该路径的前提。路径数量、预算和质量待统一端到端观察。

## 契约、失败与配额

`retrieval_candidates.py`定义明确查询、结构查询及通道描述；RAGAgent按有限顺序调用。每路声明输入表示、候选UUID、分数方向、pre-filter支持、候选上限和共享原截止时间。FTS、BM25和结构查询分别捕获可记录的调用失败；稠密编码／数据库失败保留独立状态。结果为空与调用失败分开，全部请求通道失败不能成为成功空结果。原时间耗尽停止后续通道，不为补满数量延长任务。

用户选择英文词形时，以当前数据库相同配置派生查询词形并匹配本人的同配置倒排；分数是命中词形数。用户选择学习稀疏时，任务快照冻结模型、revision、输入上限及Top-K，运行时配置变化不偷换模型；先检查当前授权范围是否有同模型已发布索引，有才在原剩余时限的40%且最多45秒内实际编码查询，使用相同模型profile和词表的token权重内积召回。没有索引时跳过本地推理；模型不可用或通道失败分别留痕，其他路线继续。两个新通道使用共同业务pre-filter、owner和生命周期限制，进入重排／返回前再次复查；模型和数据库异常不会以关键词结果冒称学习稀疏。

本人可选择整体语义和／或细粒度语义。配对模型、revision、输入前缀身份与共享空间声明随任务冻结；查询端先检查有无当前授权且同配对的代际，随后实际编码并核对维度、归一化和库版本。整体语义在最多2000个可访问片段上按实际归一向量点积精确排序，超出或期限到达记录覆盖不完整。细粒度路线从整体向量有界候选中最多选择30个，读取最多16 MiB实际token矩阵，只对可映射到查询及来源原文的token计算每个查询token的最大余弦分数之和；总标量乘法最多1.2亿，未评分候选和覆盖范围分开记录，不把截断结果称为全集。该MaxSim思路可参考[ColBERT论文](https://arxiv.org/abs/2004.12832)，但普通配对模型的输出不因此成为ColBERT训练模型；配对空间由部署者声明，实际有效性需统一端到端评估。

本人选择图文匹配时，冻结本地图文模型身份，先查可访问范围是否存在相同模型且具有原文位置的当前图片代际；有才在原剩余期限的40%且最多45秒内编码查询。图像向量与文本查询做归一化点积，扫描最多2000对图片／片段并记录覆盖；仅与该PDF页或DOCX已关联结构块文字区间重叠的原文片段进入研究候选。图片相似度是发现线索，并不表示模型读懂图片或图片支持任何事实。进入重排、返回及新综合前均复核来源和图片代际。缺图片、原文范围或模型时记录对应状态，其他通道保留。音频检索尚未实现。

资料库可独立浏览已索引图片，使用本人描述文字找图片，或以某张已编码图片找相似图片；这些结果可包含没有提取文字的图片，但不会伪造文字证据。查询最多扫描1000张同模型图片，返回实际相似度及截断状态。选择的原件生成最多1.4 MB的JPEG预览、每个来源最多保留10 MiB，来源撤销／失效或切换代际后预览不可访问；原文件及原图字节不留存。行为模型／授权数据和社区摘要继续记录skipped原因；未配置模型和索引的通道没有假造数值或成功状态。

候选经过OPT-10共同范围与消费前复查，原始排名和结构路径随任务证据保存；工作区展开实际通道和缺口。外网来源继续保留为任务证据，重复引用或反复修订不自动向量化，也不自动导入内部知识库。源内上下文选择和外网发现工具均不拥有一轮独立自主思考。
