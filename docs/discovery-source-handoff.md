# 从研究问题到成果正文

2026-10-28。M1真实任务91ad1ba6只取得机构／新闻等正文，补读12项全部是第一层，采纳发表为0。取得页面不等于完成了目标研究；这些失败记录继续保留。

## 用途与输入

`discovery_handoff.py`为原根工具计划选择下一次公开读取，不是新的Agent。新任务冻结`adrs-discovery-handoff-v2`，输入原始问题、显式机构名／别名、当前保留证据、工具状态、原来源限制和剩余预算。开放机构研究保留原问题检索及成果发现入口；模型仍负责有意义的技术翻译和分解，不允许凭记忆预塞论文名单。显式只读种子不增加检索。

原始主题去掉显式机构名和通用研究词，作为词面选择信号。机构名命中、官网域名、新闻中出现“科研”均不能代替具体主题。选择不是科学支持或机构归属证明，采纳成果继续走原文署名、日期和身份校验。

新合同对单对象静态初始查询只保留原问题、成果与团队三条，把余量留给正文；移出的初始查询保留在计划调整中。条件或资料依赖及多对象不套这一限制，无效DAG仍交给原编译器处理。最后一批工具结果聚合后也会安排补读，避免直接路由分析而遗漏交接。

## 调度与输出

先消费当前已安排的补读，再扩展下一批，避免在父页面尚未返回时把全部名额花在第一层。每次最多3项，总补读仍最多12项；新策略最多3层，允许“团队页—发表页—该页明确全文链接”。纯机构背景入口每份发现计划最多4项，相关成果和全文线索优先；主文献尚无全文时仍保留实际缺口。

输出仍是原DAG节点和版本化计划，记录来源证据ID、实际URL／锚文本、依赖、深度、来源角色、主题命中及选择依据。链接必须来自本任务公开搜索线索或已取得页面；PDF以来源明确链接为准，不推测URL。`citation_pdf_url`及正文链接另保留有界的研究链接视图，避免被长导航菜单截掉；原公共链接顺序保留供旧合同使用。

## 权限、预算和失败

沿用当前根owner／execution、工具许可交集、`admit_corpus_request`、`authorize_network`、公开URL／重定向及敏感URL约束。每次读取使用原根工具收据、调用／期限／并发和节点限制。没有新增模型阶段、数据库或权限；目录排序不会给来源签发可信身份。

无相关候选、名额耗尽、深度／权限限制时不制造替代来源。当前已读证据继续原分析和缺口处理；下游不能因此断言目标没有研究。旧v1及无发现策略任务保持原规则和用量期限，新规则不重新调度旧任务。

新合同的分析与写作排除搜索摘要作为原文，保留原引用编号；模块正文和附录只接受已取得来源。抽取后没有合格成果且请求深读时保留明确发现缺口，停止继续铺写空泛章节，节省后续写作和审核调用；这一状态不证明目标机构没有成果。原合同缺少相应标志时保持旧行为。
