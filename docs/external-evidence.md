# 外网取证、时间与任务内复用

对应OPT-12。**源码已接入，未运行网络、浏览器、API、SQL、模型或检查；全部TODO实现后统一端到端。** 复用原渠道、HTTP网关、PDF／HTML解析、组织验证及证据账本，不增加自主研究Agent。

## 实际读取与份额

公开研究继续默认联网。原Planner决定独立子问题，查询变体受OPT-09约束；并行只由原根调度器分配份额。普通web默认先经pinned HTTP读取HTML／JSON／文本或PDF正文，JSON、表格、版式及全文状态使用原解析器。auto在空页面或有界JavaScript占位页需要时，最多追加一次受控DOM读取；source只读原文，rendered明确选择浏览器。限定来源／只读种子不支持rendered，预览要求调整，执行也拒绝，不静默放宽域名准入。

每次HTTP跳转在连接前重新检查URL，并消耗同一请求份额；主文档、页面资源和重试使用原期限。HTTP后端与浏览网关的实际call_count进入原工具历史。默认浏览入口不分析页面模型，显式analyze_page也不能绕过根Analyst。同步浏览不因任意RuntimeError重跑，根包装结束关闭自己的浏览资源。

原选中平台API／CLI在auto模式仍走原ChannelService及owner配置；CLI的一个受控调用不等于其内部每个HTTP请求均可观察。原工具操作、已观察HTTP请求和结果未知分别记录，不声称上游CLI内部请求已逐个计量。浏览或解析线程超时不能由Python即时强杀，原传输期限及根迟到结果拒绝继续适用。

## 请求身份与缓存

新根冻结external_evidence版本、web_read_mode、web_cache_hours（0—8760，默认24）及非秘密解析配置；实时需求另使用原max_age_hours。阶段Send保留这组必要配置，并继续绑定query_context_identity。URL身份只规范化scheme／host／默认端口／空路径及fragment，保留路径大小写、文档版本和原query次序；成果家族归并不再代替网络请求身份。

新种子保存version_and_query_preserving_v1。旧任务尽量从原seed_urls或冻结对象入口恢复原请求，不能用归并后的论文URL允许其他版本。跳转仍按既有来源范围检查，实际最终URL和请求URL分别保存，不谎称取得了未读的版本。

只在当前任务已有受控公开读取原文时复用，选择最新可用版本；搜索摘要、认证平台结果及未确认传输的旧资料不作为这个公开缓存。复用前重新检查本次来源范围和年龄，未知／无时区的旧时间不冒称新鲜。服务器no-store／no-cache、较短max-age和Expires会收紧复用；DOM记录已观察资源的缓存限制，初始HTTP头与动态页面文本的作用域分别说明。ETag只是保留，不声称已实现条件GET或重新验证。

复用不改原evidence_id、原文、定位、获取时间或版本。超时或过期只影响新请求／新综合的可用性，历史原稿和引用继续保存。实时资料进入分析、审核及绘图前复查抓取年龄与当前来源范围，失效资料留下具体缺口并清除依赖的旧综合，不通过修改时间或新根补额度掩盖失败。

## 时间、来源与重复

source_fetched_at是本地开始取得资料的保守时间，collected_at记录取得后保存；发表、事件、网页更新、HTTP资源更新和缓存到期分别存入source_time_declarations。页面meta是来源声明，HTTP Date／Last-Modified不是论文发表／事件时间，不由获取时间推断出版时间。

原出版商／论文集、DBLP、arXiv、Scholar发现及官网范围继续执行。来源域名分组只是配置匹配，不能当真实性认证；搜索片段为线索，全文、元数据、预印本与产品／项目资料各保留用途。独立核对继续由原validation与主张审核接收文字依据；同一域名、论文数量、专利存在或官方页面标题不能自动证明落地或合作意愿。

任务账本对新增版本记录严格相同保留文字的body_identity，重复组保留全部来源／版本／证据ID，不删除引用，不把同文镜像当独立来源支持，也不把字节相同冒称语义等价。未知旧版本不伪造历史计算；语义近重复模型未因本次实现自动增加，后续融合仍须保留来源差异。

## 明确归档

证据接入面板可将当前受控公开原文版本保存到本人资料：

`POST /api/v1/research/{session_id}/evidence/{evidence_id}/archive`

请求含request_id、version_id、group_name和可选name。服务端检查认证owner、保留版本、受控公开传输／正文覆盖及当前来源范围；只保存取得文字及原始task／evidence／version／acquisition关联，不接受搜索线索、内部资料或生成报告冒充公开原文。默认direct、dense=false、本人group，不自动进入搜索／向量库；用户可在原资料管理中另行启用。

复用现有来源写入和生命周期操作账本，同一owner/request_id在事务锁内同参数重放得到原结果，换参数冲突。重试不重新取网、不调用模型、不改变原研究；归档的是文字版本，不是原始网络PDF字节，也不是新增事实验证。未确认公开传输的历史版本显示不可归档，可继续按原历史阅读契约查看。
