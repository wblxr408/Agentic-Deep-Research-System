## 选择与模型输入

`source_priority`保留原引用编号，对当前问题做最多160个字面词项的匹配，优先显式当前成果的publication／identity引用；深读中全文覆盖可提高选段效用，同域来源过多有有限扣分。该效用描述材料选择，不判断事实支持、学术质量或官网真实性。identity-only批次只接收其显式选中来源，避免跨论文归属混合。

原文继续按现有UTF-8总额度和完整JSON记录装配。深读保留机制、方法、实验设计、比较基线、条件、结果及局限窗口，重叠窗口合并后保留所有用途；版面截断和未选字段可见。图像／表格／跨段条件未取得时不自动补造。压缩只是抽取，模型不能把“selected_window”当阅读完整或语义已证实。

2026-10-27 全文装配补充：新任务的每个深读成果，如果自身关联资料中确实取得全文，优先选取至少一个关联全文的正文窗口；多个版本不要求全部进入。窗口超出单来源额度时，以实际 UTF-8 JSON 大小选择连续原文，保留准确字符位置与可用页码，为后续窗口保留空间；已定位的完整 proof 在空间不足时整段保留或不选。模型调用前检查每个有全文的成果是否实际装入正文窗口；不足则记录成果 ID 和当前额度，交由既有有限恢复／路由处理，不能扩大原根预算或推断未取得的全文。全文不可用的成果沿原元数据／摘要及缺口规则处理。来源选中并不等于全文已完整阅读或字段已获语义支持。

模型得到问题、原编号、evidence ID、题名URL、来源覆盖、来源声明时间和字面片段／页码／位置；保留版本身份、分数和压缩统计只存研究记录，不传给写作模型作为正文素材。实际请求仍由原预算计量器准入，无新增模型轮次。

## 版本、恢复和可见结果

任务账本与选段共同使用`retained_evidence_identity`计算现有原文版本，原规则不变；既有ID不可换文。模型所见source记录与完整研究manifest分开，模型输入裁剪不删除账本文字。每段的character offset对应当前任务保留文本，段落按保留文本空行计数；不是原PDF字节偏移，未保留页码时不补造。

`analysis_binding`纳入`adrs-evidence-selection-v1`和新根的`adrs-context-packing-v2`；未带装配版本的旧检查点继续沿用v1选择及原绑定，报告装配也跟随该版本，不能混入新阶段结果。恢复仍要求原owner／execution／plan／输入身份、额度和截止时间；旧输入不符拒绝继续，可历史阅读并显式创建独立任务，不能悄悄改旧材料或重置额度。

普通研究与组织研究均保存analyst_context；report_context仍在原organization_result研究记录内。工作区“研究记录”可展开每个问题的来源、缺口、版本及全部摘录，并通过现有保留原文组件读取本人原文。交付主文和离线正文不加入这些工程诊断。旧任务缺新字段时保留旧展示，不伪造新覆盖记录。
