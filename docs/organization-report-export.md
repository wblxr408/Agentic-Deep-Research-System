# 组织研究报告口径与导出

5.4 在现有 Report 节点后追加确定性配置附录，并将同一摘要保存在 `organization_result.report_summary`。工作台、报告 Markdown 和下载文件消费本次保存的数据，不查询当前目录、默认权重或新网页；不增加 Agent、表或导出后台服务。

## 保存契约

`app/organization_report.py` 的 `build_report_summary(configuration, findings, evidence)` 接受原运行冻结配置、有来源的成果结果和已采集证据，输出 `adrs-organization-report-v1`：

- `configuration`／`weights`：原范围、个人方案版本（若有）、原始权重、生效比例、组内比例及版本化有序映射。
- `versions`／`request_frozen_at`：范围及配置规则、原请求冻结时间。该时间不冒充最后采集时间；实际来源逐条保存 `collected_at`。
- `sample`：对象、发表记录／研究家族、对象全计数／汇总并集去重、共同组与样本覆盖语义。没有成果统计时明确未知，不以网页数作论文数。
- `evaluation`：本次冻结的目录版本、来源版本／指标年、部分公开样本与授权导入要求；`applied_to_evidence=false` 时不能给本次成果套等级或声称取得指标。
- `sources`／`pending_records`／`gaps`：实际来源身份、地址、采集时间、未纳入记录和未知关系，以及样本、学科标签与语义审核的限制。

`report_summary_markdown` 将这些保存值写入报告附录；原有成果比较附录继续引用同一成果结果。生成模型不能改写程序追加的范围和权重。JSONB 仍由原运行结果落库，结果 API 通过既有 owner 查询返回。旧报告未保存摘要时不补造历史目录、比例或取证事实；其原报告仍可下载，JSON 只携带已保存的历史数据。

权重是偏好，不是科研质量或合作成功概率。此附录不把偏好配置冒充已评分；结果页另行进行的只读重排不回写原报告。

## 工作台与下载 ACI

完成研究的报告卡提供三个动作；未完成或没有正文时不提供可用下载。输入是当前 owner 已取得的完成结果和当前报告 DOM，不接受下载时覆盖对象、指标、来源或权重。

| 动作 | 输出 | 来源与缺口 |
| --- | --- | --- |
| 下载 Markdown | 原保存的完整 `report`，含程序追加的配置和成果附录 | 保留来源地址、采集时间、目录可用性和缺失说明 |
| 下载研究数据 | `adrs-report-export-v1` JSON，含会话、正文、引用、完整组织配置及组织结果 | 含完整摘要、待核记录、原文位置及发表／家族归属数据，便于复核；不导出凭据 |
| 下载 HTML | 当前 `ReportPreview` 已渲染内容，内嵌阅读样式 | 原生 `details` 可离线展开；对象、比例、版本、来源、缺口及正文共用页面数据 |

HTML 复用实际 DOM，避免浏览器另引服务端渲染包或维护第二套 Markdown 实现。GFM 表格渲染复用 `remark-gfm`，解决报告表格的阅读需要；引用通过标准 Markdown reference definitions 关联已有来源，不修改保存正文。React 文本及 Markdown 默认处理边界保留，不开启原始 HTML 执行；结构化链接仅允许 HTTP(S)。这不等于正文主张均已核实，仍应阅读原最终审计与缺口。

下载为浏览器本地 Blob，不新增采集、模型调用、研究、审批或云端发布。Markdown／JSON 与保存数据完整一致；HTML 是阅读产物，额外内联样式和页尾会话标识。完整图像资源打包、图像驱动预设、自定义模板、绘图 Skill 及报告版本差异继续由 TODO 后续项实施，不能用本项代替。

失败以页面内错误提示保留报告；未取得预览 DOM 时 HTML 下载提示稍后重试，不输出空文件。重新点击只创建本地文件，不重启研究。下载完成清理临时对象 URL。离线 HTML 保留外部来源链接，访问原文仍需要网络；本阶段不打包外部图像资源。
