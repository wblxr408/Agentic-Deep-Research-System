# 学科分类、版本与同证据重分类

7.3 的普通契约与计算位于 `app/organization_taxonomy.py`；复用现有研究结果、原文与 PostgreSQL JSONB，不增加 Agent、模型调用或存储服务。新研究冻结 `organization_research.taxonomy`，采用运行结构 v5；旧会话保持原配置，用户可以显式为旧成果创建分类版本。

## 规则、原文和分类含义

问题 `problem`、方法 `method`、应用 `application` 分开保存。每个分类节点有 ID、名称、学科、核心 `core`／关联 `associated` 角色、词组，以及可选父节点。父子须处于同一学科和层次，循环、重复 ID、未知父节点、无规则的叶节点被拒绝。每个成果可命中多个节点，父节点作为层次路径保留，不能把多个标签当多篇成果。

提供材料科学、计算机科学、商科产品预设，以及任意已选学科的自定义分类。`auto` 只为已识别学科装配预设；未支持学科保留未知，不回退到计网或 CCF。载体评价、范围硬条件、匹配权重与分类分别保存，分类不会改写成果归属、采纳或排除。

词组匹配主成果题名，以及 HTML 中明确标记的出版商 abstract 容器段落。每项保存原文 evidence ID、URL、字符范围、字面引语和匹配字段；标题词面与摘要词面分别标明。旧材料没有保留摘要位置时只使用已保存题名，不能用页面其他参考文献补出摘要。新读取器保留正文容器外、出版商明确提供的有序 citation_author／citation_author_institution 元数据；HTML 全页保留量仍受既有上限控制，摘要位置必须实际存在于保留正文。

这是可编辑、有原文锚点的方向映射。词组出现不独立证明研究的新颖性、方法完整性或技术成熟度；含否定、背景、歧义的命中仍需人工复核。未命中保持各层次 unknown，不作低质量或零分，不推断为该方向不存在。不能以此声称所有学科语义分类或全文机制分析已经完成。材料学新研究、同证据重分类和实际下载的[端到端记录](acceptance/organization-taxonomy-20261021.md)保留成功与真实失败。

## ACI：输入、输出和错误

新研究的可选 `taxonomy` 请求：

```json
{"preset":"materials_science","version":"materials-v1","nodes":[]}
```

自定义 `preset=custom` 时 nodes 非空；预设不接受节点覆盖，需选择自定义后提交完整节点。节点示例：

```json
{"node_id":"interface","label":"界面钝化","discipline":"materials science","axis":"method","role":"core","terms":["interfacial passivation","surface passivation"],"parent_id":null}
```

`GET /api/v1/research/{session_id}/classifications` 返回首次报告分类和后续分类历史。`POST` 同一路径接收 `{"taxonomy":{...},"reason":"为何调整"}`，只从本人已完成研究的已采纳成果和保留原文计算。输入不接受替换成果、原文或外部地址；没有网络或模型调用，不重置或消耗原研究预算。

每次不同版本产生独立 snapshot ID，保存完整规则、原因、时间和结果；同一版本相同规则重复提交返回原快照，不新增业务版本。同名版本改规则返回 409，需另起版本。事务行锁串行追加 `review_status.classification_versions`，不覆盖首次 `organization_result.classification`、原文、原始请求、运行状态或报告。每个会话含首次分类最多 20 个版本。

请求节点最多 100 个，每节点最多 20 个词组；叶节点词组至少两字符，版本及标签至多 300 字符，原因 3–1000 字符。计算受已有采纳成果和保留原文上限约束，采用同步普通函数；本项没有模型重试或额外运行队列。未取得全文仍保留缺口，分类不能声称已深读。

- 401：使用现有登录认证。
- 404：不存在或不属于当前 owner；GET／POST 均重新核对归属。
- 422：无效节点、循环、学科不在原范围、预设冲突等；修改分类配置后重试。
- 409：研究未完成、无采纳样本、保留原文不可用、版本冲突或达到版本上限；先完成研究／补证，或使用新版本，不自动扩展原研究。

## 年度解释、界面与导出

年度数据只对已采纳发表按已知年计算。每个节点在每篇发表最多计一次，标签允许交叉；未观察年份单列、不补零。研究家族和正式跨图文统一统计仍由 7.8 承担，当前分类计数单位明确为发表。

重分类保存前后年度表和每项成果标签变化，包括核心／关联角色变化。结果明确标为 `reclassification_only`，记录是否使用相同成果和证据，禁止把变化说成成果数量、研发投入或内部战略增长。分类口径变化与真实新增取证分别处理。

工作台可选预设或自定义；报告冻结首次分类，结果页另有同证据分类编辑、版本回访、原文依据和独立 JSON 下载。报告 JSON 包含保存的分类历史；原 Markdown 和报告 HTML 保留首次分类口径，后续版本不回写原报告。显式重新研究携带原 taxonomy 请求，重新冻结；重分类按钮不发起新研究。
