# 候选融合与来源协调

2026-10-23源码交付，尚未运行；最终验证仍安排在全部ORG／OPT／FLOW实现之后。`app/candidate_fusion.py`是普通有界函数，由已有内部检索工具和搜索工具调用，没有增加Agent、模型调用、依赖、训练任务或数据库。

## 配置、交接及实际消费者

查询选项`candidate_fusion`经`FusionPolicy`校验，在查询解释中保存`adrs-candidate-fusion-v1`、完整默认值和`policy_id`。研究预览、历史配置编辑与本次研究使用同一配置；工具交接保留融合快照与查询类型，并纳入原operation／query-context身份。根实际调用前重新校验策略身份，未知版本和改变的配置拒绝使用，旧任务缺失时明确沿默认策略而不追认历史已冻结。

内部资料在可信owner／group／当前发布代际和业务筛选后产生literal、BM25、FTS、可选dense和structure候选；跳过的通道不参加集合运算，请求失败的通道保留失败及空集合。搜索按实际查询变体／渠道形成最多32条路径，限定来源先过滤再融合，最后仍由根复核。当前源只允许每路最多20项，配置较大值不扩大其协议上限。未获执行预算的路径保留`not_attempted`，不会制造排名。

两类工具分别融合，不把内部查询分数与联网线索分数直接相加。内部证据继续携带source／chunk／parse／feature／generation／access revision；联网URL身份保持文档版本及查询参数，保留所有观察的实际query、provider rank、渠道、后端、取得时间、标题和片段。规范化同一ID只合并候选的路径成员，不合并源文版本或引用ID。

## 方法及边界

| 配置 | 实际行为 |
| --- | --- |
| `set_mode: union / intersection` | 并集保留任一路候选；交集要求全部请求路径都包含此ID。空、失败或未执行路径不会被悄悄删除来扩大交集，路径缺口仍记录。 |
| `method: rrf` | 按每路原始顺序使用`(k+1)/(k+rank)`再加权，等价于统一常数缩放的RRF；原始RRF另保留于内部结果字段。 |
| `method: borda` | 按每路有效候选数归一化Borda排名分值；没有跨路原始分数相加。 |
| `method: min_max` | 先统一高／低分方向，再按该路最小最大值归一化；常量路取0.5。 |
| `method: z_score` | 记录该路总体均值、标准差及每项z值，再经标准正态CDF转为0—1后加权；常量路取0.5。 |
| 缺分数／非有限／异常巨大分数 | 该路显式采用排名RRF并记录原因；联网不把旧的固定0.7当成真实相关性。 |
| `weights`、`query_aware` | 用户按七种路线家族设置正权重；显式字面选择器提升literal，aggregate提升结构／字面路。规则和实际权重保存，身份与事实可靠性不会因加权提升。 |
| `per_route_top_k`、`global_top_k` | 各1—100；先逐路取额，再在全局上限内按原路线顺序预留候选。每路最低份额是尽力满足的覆盖目标，总额不足不会突破上限。 |
| `diversity: mmr / none` | 在最多100候选上按词面集合重叠计算MMR，保留每次选择的相关性、冗余和路径份额原因；没有调用嵌入或语义去重模型。 |

内部metadata-only模式使用原查询的入库／ID顺序，显式覆盖为Borda、无多样性、无份额改序，不把该结果标为相关性排名。父级原文扩展只改变返回上下文，不改变原匹配块和融合分数；上下文模式不再覆盖后续子问题的检索模式。

近重复仅在有界候选池内按最多4000字符、512词面单元及Jaccard阈值分组。所有候选和来源仍保留，分组不是同一文档、语义等价、真实实体关系或独立佐证的证明。`source_groups`用于同源聚合，原始路径与来源身份继续可查。联网发现结果仍只作为线索，支持度须回到原文。

可选Cross-Encoder属于OPT-14，独立于融合；实际成功时它会改变最终顺序，失败则保留已形成的融合／多样性顺序。路径最低份额、近重复分组和全局计数描述的是精排前候选池，不保证精排或根最终截取后的每路覆盖。

## 学习式融合的采用条件

当前没有获准且版本化的query—candidate相关性标注、分层数据划分、训练模型及可复核收益，`learning_to_rank`明确为`not_enabled`，请求不支持的方法会被类型契约拒绝。后续标注需保存查询及研究类型、当前授权候选／来源版本、相关等级、人工依据、时间划分、标注许可与模型／特征版本；来源支持度另行标注。不得把点击、已有排名或模型自评直接当真值。启用前需在授权范围内证明检索与最终报告效用有增益，并保留无模型融合路径；当前没有训练、回放或收益结论。
