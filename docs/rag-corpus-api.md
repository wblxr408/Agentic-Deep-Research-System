# RAG论文目录接合ACI

此页对应原架构任务4.3及3.1／5.2的资料侧前置。实现沿现有`document_sources`、来源生命周期、索引和任务快照，不增加目录数据库或缓存服务。当前仅源码完成，百篇全链与真实接受仍未完成。

任务侧现已复用原Analyst phase检查点保存`corpus_progress`，通过现有研究质量接口和“资料覆盖与统计依据”详情投影。其成员目前是当前已接受成果，尚不代表原目录全部候选／排除项，也未完成从所选RAG集合冻结所需全部成员的消费者。

## 资料记录

沿已有`POST /api/v1/documents/sources`，在metadata中可指定：

```json
{
  "research_record": {
    "schema_version": "adrs-rag-research-record-v1",
    "work_id": "work:example",
    "kind": "abstract",
    "primary_sources": []
  }
}
```

`work_id`由已有作品身份或显式导入映射提供，不做题名模糊合并；同一作品可以关联书目、摘要、原文和不同正式版本。kind为`bibliography`、`abstract`、`fulltext`或`derived_card`。这是资料分类，不证明原件真实、模型已读全文或来源主张已核实。旧未分类资料保持未知，不自动补为fulltext。

派生卡必须带`primary_sources`，每项含本人现有的`source_id`和精确`parse_version_id`；入库在原owner事务内核对所属和版本，拒绝以另一张派生卡作为原始来源。引用历史来源不授予当前任务读取权限，也不把引用关系变成事实支持。

记录类型和作品／版本关联参与原入库去重，防止同文但不同身份或原文／派生类别被错误合并。原有解析、分块、嵌入、索引和去重机制继续承接。research_record作为来源身份的一部分，普通元数据PUT不能修改或移除；新资料／版本沿已有接入接口。此页没有实现旧JSON／TSV导入器，也没有导入旧211条资料。

## 目录枚举

`GET /api/v1/documents/sources/catalog`只读取本人资料源的有限目录字段，始终不返回原文／分块大对象。参数：

| 参数 | 合同 |
|---|---|
| group_name | 可选，本人的精确分组，最多100字符 |
| record_kind | 可选，上述四种记录类型 |
| work_id | 可选，精确作品标识，最多260字符 |
| status | 可选，active／archived |
| lifecycle_state | 可选，retained／tombstone／legacy |
| is_current | 可选，生命周期的当前版本标志；旧未知值不冒充true |
| page_size | 1—200，默认100 |
| cursor | 上页next_cursor，不透明、有界，须保持同一查询范围和page_size |

结果含资料ID、作品／记录类型、来源与解析版本、来源生命周期、索引模式／代际、当前页items和next_cursor。每页在只读repeatable-read事务中读取原owner访问代际；资料新增、撤销、版本发布或元数据改变使旧游标返回409 `catalog_snapshot_changed_restart_enumeration`。游标损坏或跨查询范围使用返回422。页序使用时间与UUID稳定排序，旧缺失时间只使用内部排序值，保留其原始时间未知状态。

每项是来源版本记录，不能把100条来源行当成100篇不同作品。`enumeration_complete`仅说明当前快照没有下一页，不证明从第一页完整处理、更不证明筛选／精读／审核完成。后续任务成员快照必须收齐所需页并按作品身份接合；当前没有自动把资料库全部资料塞进研究上下文。

目录列出本人可以管理的资料，含未索引／旧版本／归档／删除状态。列表可见不等于当前任务可以检索或读取；执行时继续沿任务／分组／owner、有效期、当前来源及索引代际复核。筛选与阅读状态属于具体任务，当前此端点只过滤来源状态，未实现跨任务通用的“已读”字段。

## 证据检索与后续深读

现有类型化检索过滤新增work_id和record_kind，SQL表达式由服务端固定，客户端值仅参数化绑定；原权限与当前代际条件仍以AND组合。所有原文证据候选路径及返回前过滤共用的current_document_clause排除derived_card。当前派生卡由目录导航，未实现其独立语义导航检索，不以空证据结果冒充无相关卡片。

实际RAG返回从当前来源访问快照取得小型分类信息，并传入Evidence.acquisition。coverage继续为retrieved_internal_chunk；即使来源分类是fulltext，也不能将只检索到一个片段改记为读完整篇或自动完成技术字段。后续原文补窗、逐篇所需层级、已读字段、来源支持和共享补证继续沿原Analyst／技术卡／phase与根产物接合。

本接口没有新模型请求、目录采集后台任务或写入。资料接入仍遵守原功能与模型配置；读取目录不触发重新切块／嵌入，任务筛选状态将独立于来源身份处理。未找到、未分类、未索引、未取得全文、未读、未审核是不同状态。

## 任务阅读与补证状态

新任务沿版本化章节政策启用任务进度；旧根不因此迁移。原Analyst范围识别后登记接受成员；原reading_plan／representative_reading保存选择角色和理由，未选项保留；原两篇一批与字段原文校验结果更新逐篇状态。必要字段沿现有条件补读政策：experimental_design、baselines、conditions、results，以及该阶段合同要求的mechanism。其他已取得字段仍保留，当前不把这五字段覆盖称为全部十字段或整篇全文精读通过。

每篇保存实际材料层级、所需／已定位／缺失字段、来源ID／版本（可取得时）及原phase定位。`required_fields_located`仅指现有必要字段有已定位候选，full_document_read保持false，事实支持不会由该状态授予。没有资料或字段返回时留缺口，不据摘要推断原论文缺少内容。

缺字段沿同一个work_id记录，原两篇共享的条件补读仍使用原phase_id和机会；来源未取得全文与有全文但字段未建立分列。恢复在同一有效分析绑定内消费已保存phase结果，再重建进度，不新增补证Agent、目录权威或一套预算。补读结束仍可completed_with_gaps，不能重置原次数或当作字段已补齐。原根参数不变。

adaptive_budget在有效进度／选择合同下按未读成员和去重的待补读phase预测，避免把一次条件补读当作又完成了一批初读。预留只是估算，不批准跳过工作或扩大额度。新增／变更来源使全局分析绑定变化后的精确差量接续、按新缺口调DAG读原文、最终事实／读者缺口回流和完整未入选目录接合仍待继续实施，当前没有“新增一篇绝不重读99篇”的运行证据。
