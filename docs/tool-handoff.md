# 主流程工具交接 ACI

本次沿用Python/LangGraph、原PostgreSQL快照和单一根预算，不增加服务或优化算法。`app/tool_handoff.py`连接根调度、一个工具请求与根结果接纳；工具不是另一个自主研究循环。

## 任务与上下文

根DAG执行器按已选批次分配互不重复的调用份额，期限取节点超时与剩余任务时间较小者。冻结任务、owner、execution、plan_version/revision、节点、请求身份、attempt及审批状态身份，生成稳定operation_id；审批改变会形成新操作，重复未改变的请求保持原身份。

Send只含一个节点、当前工具阶段冻结Skill、来源/对象范围、根预算摘要、必要会话身份/通道、该节点审批及明确复用的同URL证据。没有完整分析、报告、权重/评价目录、全部工具历史、其他阶段技能或兄弟DAG。旧任务无manifest时从实际恢复DAG生成兼容绑定，保留原执行状态，不重新规划或套用今日Skill。

2026-10-23源码延续：搜索交接保留冻结对象／时间、术语变体和时效口径，内部取证保留过滤策略及召回模式，浏览保留时效口径；各自仍只接收实际要用的字段。交接保存query_context_identity并纳入operation_id，工具执行前复核实际投影，根接纳核对同一身份，避免配置已保存但在Send中丢失。该身份仅做一致性，实际权限仍由网关执行。旧绑定缺该字段时保留legacy语义，不追认具有新范围绑定；新字段和原有异常路径待最后统一端到端。

## 执行与接纳

受信包装器在调用前和返回后查询数据库实际owner/execution及运行状态，检查任务期限；异步MCP直接等待，现有同步取证在受限时限内执行。原工具网关继续控制来源、授权、审批与网络；交接字段不替代这些执行边界。

工具只返回包络，不直接向根collected_evidence写入。根聚合再次核对当前执行及计划/节点/请求/attempt/审批身份，重复operation仅确认一次，旧版本不能改变同名新节点，也不能进入综合。当前批次的结果状态必须匹配分发operation；节点结果数量从接纳结果生成，不信任旧计划同名outcome。

超时、已撤销执行及其他未知结果不保留原始返回资料进入模型，只记录结果未知及保守消耗的调用份额，节点留缺口，不自动重新授予预算。成功结果按实际工具调用结算，已接纳操作不重复入账。超时线程不能由Python强杀，原HTTP/浏览器/解析期限继续约束实际工作；不能承诺外部请求exactly-once、免费失败或不重复模型计费。

包络在现有JSONB保存，接纳后替换为确认标记并保留operation审计；恢复沿用这些字段。SSE仅发送交接字段的计数和结果原因，不广播完整工具包络。
