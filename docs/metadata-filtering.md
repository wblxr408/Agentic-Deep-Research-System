# 内部资料过滤与当前范围

对应OPT-10。**源码已接入，未运行SQL、API、模型、浏览器、构建或任何测试；全部TODO实现后统一端到端。** 复用原Python／Pydantic／PostgreSQL及索引，不新增过滤服务、位图库或数据库。

## 用户条件与冻结

查询面板支持`query_options.internal_filter` JSON，最多8个OR组、每组8个AND条件、合计32条件及16000字符。字段为source_id、group_name、source_name、source_type、format、chunk_kind、chunk_index、created_at；操作为eq／ne／in／not_in／gte／lte／exists／missing。集合最多32个值，标量使用字符串；source_id解析UUID，chunk_index转为有界整数，created_at解析含时区时间。范围操作只用于整数／时间，未知字段、操作、类型或策略拒绝。示例：

```json
{"any_of":[{"all_of":[
  {"field":"format","op":"eq","value":".pdf"},
  {"field":"created_at","op":"gte","value":"2026-01-01T00:00:00+08:00"}
]}],"strategy":"auto"}
```

created_at是入库时间，不能替代发表／事件时间。字段缺失指SQL NULL，比较及否定比较均排除缺失，明确missing／exists才判断存在性；ne不是“缺失也满足”。空any_of只表示无额外业务条件。内部资料未启用却填写条件会要求处理配置，不能悄悄忽略。

预览与创建复算并冻结同一类型化策略、版本及filter_id，历史恢复使用原快照。执行入口核对版本、策略和身份后才传递条件；旧任务缺该字段时保持原有业务范围。filter_id用于一致性，不是独立授权凭据。

## 执行与选择率

所有业务OR组外面始终还有独立的可信AND：当前owner、显式group、source active、生命周期有效期／复用范围、当前head／已发布代际及解析／特征版本。客户端不能声明owner或提供SQL字段路径。`app/retrieval_filters.py`只从固定字段表达式和操作符编译SQL，值通过参数传递。

词汇FTS、BM25的N／DF／候选和稠密精确距离都下推同一业务谓词；不会把过滤前统计冒充过滤后语料统计。当前选择pre-filter，精确距离先物化合法集合后排序，不受近似索引后过滤丢失Top-K影响。auto也选此路径；未实现的post-filter和in-search图遍历不能作为可用选项，不能无法下推时先把未授权内容交给模型再过滤。

每次检索最多观察10001个本人当前可用块，记录观察量、其中符合条件量和保留比例。观察达到上限时不推断全库规模或整体比例；观察为空时比例未知。保留比例越小表示过滤越严格，与查询相关性、样本完整性无关。候选查询仍检索完整合法集合，不被观察上限裁掉。

候选上限取已配置初始数量与最终目标三倍的较大者，最多100。Top-K仍不足时保留短缺与当前精确路径，不放宽owner、版本或业务条件；没有未实现的ANN路径可回退。元数据条件由已有B-Tree、GIN及参数化SQL计算；当前没有测得必须启用Roaring Bitmap、额外分区或过滤图索引的必要性，也没有宣称已完成性能优化。

## 内容消费边界

候选内容进入可选重排前，重新核对当前合法文档ID、发布代际、业务条件及原来源access revision。父级／开头扩展继续核对原来源权限与版本，整批返回前再复查合法ID及revision。业务的chunk_kind／chunk_index作用于匹配块；明确选择的父级上下文是同源补充，并在returned_span与retrieval_score_scope说明，不把扩展文字当作独立命中或评分依据。检查发生在消费边界，不承诺撤权能抹去已经发出的请求。

根RAG节点使用原剩余时间限制整次异步检索，超时留下具体原因；同步包装在finally关闭自身连接池，不因任意RuntimeError自动再执行一次。事件循环内调用者应使用execute_async或现有async context manager。根逐个处理本批RAG节点，不再静默只处理第一个。其他历史独立调用未提供timeout时保留其原时限语义，不冒称已受新根截止时间约束。

工具历史、来源证据元数据和工作区轨迹保留过滤计划、观察范围、实际候选／返回及不足原因；报告正文不自动插入这些运行字段。缓存结果不具有额外许可，当前复查失败就拒绝进入重排或返回。并发变更后的结果可能更少，不用旧缓存填满数量。
