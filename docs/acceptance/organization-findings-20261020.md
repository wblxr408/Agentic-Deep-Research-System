## 行为与证据

目标是从出版商的单篇共同署名成果提取发表日期与历史机构署名，分别展示两所高校和一家企业，并使报告、API 和保存的计数一致。原始主来源为 [USENIX DistServe 页面](https://www.usenix.org/conference/osdi24/presentation/zhong-yinmin)。这是一条有界样本研究，不是机构成果全集或正式合作关系调查。

初始真实研究 `a87adca0-8acc-4dfa-8fc5-8d0c3b901ebd` 完成后缺少 `scope_result`，消费程序失败。接入分析后，`8fc63d88-746a-400a-b934-362f73dbf067` 又暴露结构返回缺失；修复 JSON 根对象／外层围栏解析和格式指令后，`cfe12956-18cc-4166-a094-01c8553f354b` 的短标题摘录未满足完整标题要求。`1a2d6512-7d04-48b0-b379-ec16d79aa098` 暴露日期摘录被模型加省略号，以及 BibTeX 年月分列与 ISO 精度的差异。以上都按真实失败处理，没有改预期数量或替换来源。

实现复用原 Analyst 调用，保存结构化返回；浏览保留隐藏出版元数据并去重引用面板。完整标题可在同份原文定位；BibTeX 年月字段由代码规范化，保留各字段原文位置。错误引文不能通过模糊匹配充当原文。

最终真实研究 **`6533d261-19b7-47bc-9031-5c9237c1bf36`** 的完整消费程序退出 0：

- PKU、UC San Diego、StepFun 三个对象分别关联同一篇 DistServe，发表记录和研究单元各 1；联合汇总为 1，不相加为 3。
- 2024 年会议论文组包含同一组三个对象；分组明确是样本比较，不作科研质量排序。
- 日期根据出版商 `year=2024`／`month=jul` 保存为 2024-07-01 至 2024-07-31、month 精度，而非虚构精确发表日。
- 15 处 `quote` 与保存原文的 `[start:end]` 完全对应；发表归属、日期、比较组、建议、缺口写入 API 和 PostgreSQL 同一快照。
- 报告中的确定性对象表与结构化计数一致，带依据建议在报告出现；资助保留 `not_established`。未确立的关系不解释为不存在。
- 报告 13,992 字符，引用列表 31 条；数量不等于全部引用正确。没有额外 Agent 或独立抽取模型调用。

运行入口为 `scripts/organization_outputs_e2e.py`。如只需继续观察同一实际任务，可使用 `--session <ID>`，不会另建研究。首次观察超时不表示后台任务终止。
