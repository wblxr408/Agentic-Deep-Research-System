全路径生成报告后，追加的页面显示和刷新验证使用**同一个已完成会话**继续消费；未把多次回访称作多次新研究。验收脚本为 [`scripts/organization_e2e.py`](../../scripts/organization_e2e.py)，不带参数创建真实新研究，传入会话 ID 仅继续读取和验证已存在的业务产物。
