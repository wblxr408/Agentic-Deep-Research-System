## 初始失败与修复

旧实现对已有材料学研究请求 `POST /research/{id}/classifications` 返回 404，无法完成同证据分类；原始响应保存在随附目录的 `baseline.json`。

新分类集成后的第一轮研究 `a9644166-8208-49a7-b77c-c15f3bf00ccb` 完成但没有已采纳成果：读取正文时丢掉了正文容器外的作者信息，模型没有提出可核对署名。改为保留可见页面后，第二轮 `f7ad8d4f-03e9-4532-9573-433815a22062` 仍失败：通用解析器也会隐藏页眉中的作者卡片。原始 HTML 直接显示了 `citation_author` 及紧随其后的 `citation_author_institution` 元数据。

最终读取器保留出版商按原顺序提供的 citation 元数据和正文。只解析明确字段、保留原值及多个机构，不根据资助机构猜作者单位；多个不同主标题不组装单一元数据前缀。摘要从明确 abstract 容器段落定位到保留正文，位置重新按最终文本计算。没有放宽成果归属校验。两次失败及对应待核记录保存到 `failed-attempts.json`，不能当作成功研究。

## 页面重分类、历史和权限

真实结果页选择自定义，保存 `materials-e2e-v2`：新增“材料界面方法”父级及“双阳离子策略”交叉标签，将表面钝化改为关联方向。取得 6 项标签；双阳离子来自同一保留摘要，不触发新采集或模型。前后成果及证据 ID 一致，年度发表数仍是 1；保存的变化类型为 `reclassification_only`，明确禁止增长解释。
