# 浏览器双账号与弱网试用 · 2026-10-25

用户追加授权继续多用户功能的浏览器双账号与弱网试用。复用 `add-multi-user-workspaces`，在本地独立 Edge 中执行真实页面、真实 HTTP 和原专用 PostgreSQL 数据库的路径。此次不启动研究图或付费模型，不运行其他回归、构建、类型、lint、schema 或探针。

## 环境与方法

- Edge 使用独立非持久 profile，同一 context 的两个页面共享 Cookie 和 localStorage，覆盖实际跨标签认证通知。
- 独立前端 5181 代理专用 API 8011；复用上一轮创建的 A/B 普通账号和保留任务，增加 A/B 各自的资料与不同模型配置作为可辨识样本。生产 5177／8009 的原账号、数据和密码没有用于切换试用。
- 限速由浏览器网络控制实施：延迟 900ms、下载 64KB/s、上传 32KB/s；断网使用浏览器 context 离线模式。没有修改用户系统网络设置。
- 延迟认证和资料时，先取得服务端真实响应，再控制何时交还浏览器；不伪造身份、状态码或响应内容。认证请求延迟 12 秒，超过应用 10 秒超时。
- 截图、逐场景结果和一次性操作脚本保留在本机 `outputs/accounts-browser-20261025/`、`.codex-homework/`，不提交私有凭证、浏览器会话或网络追踪正文。

## 通过的九个场景

| 场景 | 实际结果 |
| --- | --- |
| A 的资料与保留任务 | 两标签均显示 A 身份；能读取 A 资料及保留任务，资料列表不含 B 条目 |
| 同身份导航 | A 输入未提交草稿后在研究／资料之间往返，草稿保留 |
| A 退出、B 登录 | 另一标签同步注销并清除任务正文，随后同步 B 身份；旧任务 URL 标识移除、草稿为空，显示 B 资料及模型，不含 A 数据 |
| 切换回 A | 恢复 A 自己的资料，不显示 B 条目 |
| 900ms／64KB/s／32KB/s | 实际设置页、退出和另一账号登录完成，身份和模型归属正确 |
| A 身份响应迟到 | A 的真实 `/auth/me` 响应保留到 B 登录并跨标签同步后才释放，旧响应没有覆盖 B 身份 |
| 12 秒认证延迟 | 显示“连接超时，请重试”，私有身份和页面隐藏；移除延迟并点击重新连接后恢复当前 B 身份 |
| 断网退出与恢复 | 退出请求断网时明确显示未完成，不冒充服务端已注销；恢复连接后重试成功，随后可登录 A |
| A 资料响应迟到 | A 的真实资料列表响应在 B 身份和资料已显示后才释放；DOM 观察没有出现 A 条目，页面渲染及研究／资料往返后仍只有 B 的资料 |

前八个场景在同一完整浏览器旅程中最终通过，第九个在独立浏览器操作中验证迟到资料和缓存重用。修复后的旅程没有未处理的浏览器页面异常。截图为自动化操作的实际页面，不是设计稿；这些结果不等于真人对易用性的主观评价，也不替代原研究质量／图文导出验收。

## 实际发现与修复

1. **无节点记录的保留任务导致白屏**：浏览器取得任务后，`ResearchFlow` 对空执行计划的 `nodes.map` 直接取值，出现实际 `TypeError`。改为对 nodes 也做空值处理，原保留任务可正常打开，随后完整切换路径通过。
2. **已保存自定义模型显示不一致**：当前模型卡片显示 B 的模型，但下拉框因预设列表不含该模型而显示首个预设。为当前已保存且不在预设中的模型保留选项；实际页面的模型卡片和选择值均显示 B 的模型。

最初还遇到专用 API／数据库连接中断：直接访问 API 及 PostgreSQL 连接均超时，Docker 引擎 API 返回 500。按本机既定原生方式重启 Docker 并启动原 DB／Redis 容器后恢复，未删除卷。早期未完成旅程不计通过；没有将尚未证实的日志背压猜测写成根因。

收尾时原 5177 前端的认证请求返回代理 500，确认其目标 8009 已无监听进程；原 API 日志也没有收到这些请求，因此没有把该故障误判为旧数据库连接异常。确认原 9 个任务仍为 3 个失败、6 个暂停，没有创建或继续原研究任务。继续会话时发现原前端、API 及临时服务进程均已退出，Docker 引擎管道也不存在；改为从 Windows 独立隐藏进程启动原前端与 API，并使用既定原生桥启动 Docker 和原数据库容器。进程退出原因没有足够证据，本轮不作根因认定。

恢复后在独立 Edge 实际打开原地址 `http://127.0.0.1:5177/?view=register`，确认用户名、密码、确认密码及“注册并进入”表单正常显示，并保存 `retained-registration-restored.png`；未向原工作区添加试用账号。临时 5181／8011 服务已退出，原 5177／8009 服务保留。

限速与真实响应延迟方法参考 [Playwright 网络操作](https://playwright.dev/python/docs/network) 和 [BrowserContext 离线模式](https://playwright.dev/python/docs/api/class-browsercontext#browser-context-set-offline)。
