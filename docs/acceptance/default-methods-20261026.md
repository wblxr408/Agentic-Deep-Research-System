2026-10-26，本机源码实现及当前新增行为验证。45项适配文件与manifest随仓库分发，Dockerfile将同一目录复制进后端镜像，无新增依赖或数据库结构。

## 生效路径

`list_skill_meta(owner_id)`在原存储初始化后调用`ensure_default_methods`。从仓库资源读取并解析完整包，再在账号行锁和同一事务中写入本人元数据／正文；本人已有slug、稳定默认ID、停用或删除记录均保留。`ON CONFLICT DO NOTHING`同时处理已有唯一键冲突，失败由事务回滚，不留元数据／正文半成品。新默认ID按owner与规范slug生成，不是授权凭据，读取继续检查owner。

管理页全量读取和运行注册表加载均走此路径。进程启动时无principal的注册表仍为空，不加载别人的数据。当前账号前序导入45项原文保持；不重新下载源包、不执行脚本、不改变工具授权或top-k。
