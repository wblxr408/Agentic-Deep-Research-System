# 同一统计快照驱动文字、图表与导出

2026-10-21：OpenSpec 7.8 的实现已接入，待全部 TODO 实现后的统一端到端验收。这里没有新的运行通过结论。

## 计算与定位

`app/organization_statistics.py` 从本次采纳成果、显式研究家族、对象视图、分类记录及来源流转计算 `adrs-statistical-snapshot-v1`。主图在分类／样本生成后、Report 调用前计算；同一份结果进入 `organization_result.statistics` 和报告摘要。统计不调用模型、不出站、不建立新存储。

快照保存实际来源身份、分类快照 ID、taxonomy 版本、`metric_registry`、发表 ID、家族成员、按对象／年份／标签的表及图表序列、未知年份和分类、输入冲突。每个指标有 `metric_id`、值、展示精度、单位、分子／分母和成员 ID，可回到原采纳成果及证据核查。算术一致不代表原文语义、分类准确性或现实全集已核实。

## 计数规则

- 发表记录以 `output_id` 去重，冲突身份保留提示。家族只使用已有显式成员，不按标题近似合并；未链接发表是独立单元。重复家族 ID、重复成员或不可用成员不重复计入，冲突可复核。
- 各对象按全计数，联合结果取并集，不把各机构数相加。年度家族数可跨年重叠，不能直接相加当全期家族数。
- 比例用 Decimal、四舍五入到两位。9/54 的计算式是 `9 × 100 / 54`，应展示 16.67%；这只是规则说明，尚未执行新场景验证。空分母返回 null／未知。
- 一篇可属多个标签，每个标签每篇只计一次，统一分母为全部采纳发表。合计可超过 100%。没有规则命中的标签只表示样本观测为零，不能证明研究方向不存在；问题、方法、应用未知分别保留。
- 年份以已采纳发表日期区间为依据；未知或跨年区间不以元数据猜补。元数据冲突记录原值。未观察年份在图表序列中为 null 和缺失标记，不补零、不从缺年计算增长率。年份未知的待核候选与已采纳记录分别计数。
- 保留来源数／流转使用 evidence 或 URL 单位，不能冒充论文或家族数量。

## 报告及交互

Report 收到有界 `computed_statistics`。正文引用 `{stat:sample:publications}`、`{stat:year:2021:sample_share}` 等占位符，由服务端以实际快照展示值替换，并保存每段 `statistic_bindings`、原始文本及 `rendered_text`。未知指标、畸形占位符和识别出的手写样本计数／比例段落被拒绝，缺模块会明确显示缺口。技术实验数值和发表日期仍属于来源主张，不能由样本统计替代；程序边界不能代替后续独立语义审核。

确定性统计附录和前端 `StatisticsSummary` 使用同一指标注册表。年度 SVG 用虚线标示缺年，标签图明确多标签全计数；表格展开指标成员／分母。标签图最多显示 40 项并提示保留总量，完整数值在表与 JSON。图表无 CDN 依赖，现有离线 HTML 导出可保留 SVG；具体导出效果待最后验收。

同证据重分类为新分类版本附上独立统计快照，保存到现有 `classification_versions`，原报告与原统计不改写。版本选择页及分类数据下载携带该快照。旧分类不追写统计，显式查询可获得标注为非持久的投影。

## ACI

`GET /api/v1/research/{session_id}/statistics` 读取本人已完成组织研究的冻结统计；`classification_snapshot_id` 可选指定该研究的分类版本。新研究返回 `persisted=true`，旧记录投影返回 `persisted=false` 和 `origin=explicit_legacy_snapshot_projection`。它不采集、不调用模型、不修改原研究或重新花费取证预算。

404 表示会话／版本不可访问；409 表示未完成或非组织模式。来源身份必须来自服务端实际会话记录，不能由调用方上传一组数字覆盖报告。数据有冲突时返回解释及重新计算值；原文事实有误应补证或另开研究，不用改图表掩盖。

沿用 [ACI 导出契约](organization-report-export.md)和 A2ABreak v1.0 A2AB-03《上下文归属与跨租户隔离》、A2AB-06《并发状态版本与审批绑定》“工程解决方案／验收办法”章节：owner 查询与同事务追加版本为执行点；没有新增出站、Agent 或权限，其他项复用 [11 项适用性评估](OPTIMIZATION_TODO.md#安全方案引用与规划状态)。这是工程方案引用，实际隔离／一致性验证尚待统一端到端阶段。

最终场景必须包含 9/54、多标签重复、同一家族多个发表、父子／混合对象共有成果、未知年份、手写错误比例、空分母、重分类原报告保持、双 owner 及 JSON／Markdown／离线 HTML／图表同值。本阶段未执行任何用例或门禁。
