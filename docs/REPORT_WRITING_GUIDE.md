# 报告写作与研究记录

通用代码已接入核心判断、模块主文／技术附录、来源字段对照表和分别导出，取消每模块固定一至三段。实际选段、字数与语义支持仍应对照真实研究记录，不能用模板接入代替内容达到要求。见[全文上下文与读者报告](research-context-packing.md)。

2026-10-22用户明确指出：报告里的“待审核”、产物/数据版本及反复防御性措辞不符合正常研究报告。本规范适用于不同学科、企业、高校和实验室的主流程报告及其HTML、Markdown和打印交付。

## 报告读者需要的内容

围绕研究问题组织摘要、主要发现、技术分析、比较、建议和参考资料。开头用一处简洁的方法说明交代研究对象、时间、样本选择和材料范围；在具体结论处说明真正影响解释的条件。数值注明单位、分母和来源，论文实验结果归因于作者所报告的实验。

段落直接表达观点，不给每段加“来源摘述”“待审核”“分析判断待复核”“证据缺口”等工作流前缀。依据不足时缩小结论范围，或提出具体的后续研究问题。空字段、未选能力、工具权限及系统为什么不执行某动作，不为凑齐模板进入正文。

例如，“本次仅覆盖两个来源，不能保证全集、不能推断投入、没有独立审核……”应按实际研究目的改写为一次方法说明：“本文采用两篇论文的出版摘要和作者署名，比较技术机制与团队构成。”具体研究结论仍需与这些资料相符。论文数量确实不足以讨论年度变化时，应在该结论处说明需要补充哪些年度样本，而非反复加入通用免责。

## 读者质量与主文/附录

报告先回答读者需要据此做什么判断：研究对象的持续问题、机制的变化、对比的关键条件，以及下一步行动。主文围绕问题比较候选机制；逐篇完整实验条件和长表放入可展开、可单独导出的技术附录。不能用固定页数或固定每模块1—3段作为“完整报告”的标准，也不能靠增加表格和计数图证明深度。

每项建议应连接需求、研究依据、团队/资产、必要资源、首个可验收成果。用户资源未知时给出条件化路径，不臆造设备、不硬排合作分数。报告中的原始结果、跨材料分析与合作建议分别归因；预印本/正式版本、历史署名/当前任职不可混合。

质量审阅使用读者任务和真实证据，不以自评“8/10”替代验收。模型审核的partial可能来自选段不足，也可能来自真实矛盾，须定位原文区分；保留原判及后续处理。实际目标用户试读和当前作者自审分别记录。离线HTML应支持真实可用的导航/图表交互，PDF按阅读节奏分页，避免强制分节造成大量空白。

本次[北大报告质量改进](acceptance/pku-report-quality-20261022.md)是来源复核后人工整编样例；通用生成器的全文选段、上下文装配与主文/附录渲染仍见TODO FLOW.10—12，不据样例宣称已自动实现。

## 研究记录保留的信息

2026-10-24，实际A6自动稿仍把“来源文档版本／全文文档版本／零条采纳”写进研究全景，说明仅写禁止指令不够。报告写作的统计上下文现只提供已建立的研究样本指标，采集／版本指标留在完整研究记录；未建立发表样本时不提供零值作研究结论。实际成果名称、材料范围与有根据的定性分析仍可进入正文，不把统计链故障伪装成机构没有成果。完整统计注册表、图表计算和审计数据保留，此源码调整须下一真实报告取证。

审核状态及对应原文、采集/解析/统计版本、产物身份、指标ID、内部错误码、运行预算、配置快照、资料位置和结构化模块保存在原任务数据及应用专属“研究记录”入口中。工作区继续展示研究进度、计划变化和阻塞原因。JSON研究数据包含这些记录；阅读正文、HTML与打印版展示研究内容和正常参考资料。

图表展示标题、单位、数值、简洁图注和可展开数据表，来源可以通过文献链接取得。快照ID和指标ID仍绑定图表数据，但不占据图注、悬浮说明或数据列。未知年度保留空白；样本口径按实际材料说明。

## 实现位置

- `app/organization_purpose.py`：写作要求与模块组装；kind/统计绑定/拒绝原因保留在结构化结果，段落不加状态标签。
- `app/agents/report.py`、`app/graph/compiler.py`：来源审核、结构化组织结果继续保存；取消自动拼接审核文本、偏移表、配置及内部运行告示。
- `app/research_delivery.py`：历史稿仅投影旧程序明确生成的系统章节和标签；引用转为正常数字编号，保留参考资料与研究论述。不会通过全局删“未知/限制”等词处理正文。
- `ReportPreview.tsx`：报告阅读与应用专属研究记录分开。`ReportDeliveryView.tsx`只渲染研究页面、图表和参考资料。
- `ReportDownloads.tsx`：Markdown使用阅读正文，HTML/打印移除研究记录；JSON保留正文和完整研究记录。打印隐藏与图文页面重复的全文展开区。
