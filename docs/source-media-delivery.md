# 原图页与研究资料包（M2）

## 当前缺口与实现范围

现有PDF解析保存正文、页码和图像位置，`figure_references`只是来源指针，没有原始PDF或图片字节。M2在同一取证请求中保留已经取得的原始PDF，在完整报告审核后，从实际图注所在页生成原图页预览；原件、已采集正文、图注定位和报告一起形成本人可下载的资料包。图号或正文中的引用不冒充已取得图片。

原图页呈现整页实际像素，明确标为“原文第N页”，不声称已经完成精确图块分割。图片与现有根据数据生成的图表分开，预设／自定义版式和绘图Skill继续管理后者。页预览、原PDF和图注对应同一采集版本。后续精确图块适配沿相同资产接口扩展，不改现有来源和绘图职责。PDF路径跨研究对象／学科；HTML及内部资料保留原有正文／权限／来源契约，未保存原件时资料包不声称有原始二进制。

## 数据与边界

复用PostgreSQL的BYTEA能力，新增本人／任务作用域的不可变来源资产及页预览表，避免把原始二进制塞入LLM上下文、工作流JSON或增加对象存储服务。每个原件最多12MiB，根最多64MiB，超过时记录原件未保留，正文仍按原契约处理。资产保存实际请求取得的PDF和同次解析正文；读取／交付必须匹配当前任务证据、原件引用、来源和实际正文，不能跨owner／task或把其他版本原件拼接到当前证据。

取证写入使用当前执行绑定和运行状态，原网络／来源准入、根工具次数与期限保持不变，不额外抓取PDF。图像渲染不联网、不调用模型，最多8个不同原件／页组合、每项成果最多2页，页码1—80；采用现有PDF渲染能力和受控子进程，限制像素、输出字节和时长，取消沿现有执行控制回收。原图页不进入原文事实或统计的自动推断。

定位只接受当前逐字proof、无歧义页区间和真正图注前缀；拒绝“如图1所示”等正文提及、冲突页码或无法取得原件的候选。重复同一原件／页合并，不按全局页码混淆不同论文。原图页渲染后保留资产、页、图注、证据和成果的绑定，缺口记录在研究记录／资料清单，正常报告不插入内部版本／解析诊断。

资料包下载复用本人会话鉴权和当前来源权限，读取已保存资源，不在下载时联网或执行模型；包内路径由程序生成，图片使用实际PNG，原件PDF作为下载文件，清单包含来源、实际采集范围及缺失项。独立HTML应嵌入图片，下载／重开不依赖另一用户会话或本机临时文件。按报告已有原有取消、完整审核、版本和交付门禁决定是否可发布。

## 已接入源码的 ACI（运行待统一旅程）

- **采集**：`external_evidence.collect_public_source`仅对新冻结`external_evidence.source_media_policy=adrs-source-media-v2`把同一策略交给正文读取；根delivery同时保存该版本，工具不接收展示配置。`source_assets.retain_acquired_pdf`接收已获PDF字节、同次实际解析正文与原读取deadline；线程交回当前执行loop，等待最多8秒，不增加网络／模型。`db/source_assets.retain_original`在当前本人根行锁下核对active／running／execution，原字节、正文和URL相同才复用，否则追加不可变记录；取消或替换执行不得继续写。传输仍沿原8MiB请求上限，存储12MiB是额外上界，不扩大原抓取权限；根总原件64MiB。超限、截止或存储失败作为`not_retained`及原因交回，不宣称已取得图片。旧根没有策略不补下载、不回写历史原件。
- **定位与渲染**：`source_figure_locations.select_source_pages`最多20成果／每成果20候选，实际2页／成果与8原件页；proof须匹配当前原文、行首图注标签及唯一页范围。`source_media.prepare_source_media`在完整审核后重核当前来源，在根剩余期限内最多45秒，单个受控PDF渲染子进程最多15秒，取消沿`run_renderer`检查并回收。固定`source_page_renderer`只接收原始字节及有限页数组，使用既有pdfplumber渲染，页≤2百万像素／1.5MB PNG；无外部路径、脚本、网络或模型。按原件／页／渲染合同缓存，组织结果只留定位和尺寸，图片字节在DB。缺少有效图注不伪造图片；已定位页无法渲染时停止图文交付并保存原因、原报告与已留资料。
- **读取与呈现**：`source_media.owned_delivery_snapshot`从当前已完成根重取owner／task／execution并重核来源权限；`hydrate_source_media`重算原文页定位、当前证据版本和逐条proof，再以本人／根／原件／正文／URL读回实际PNG，GET不渲染、不联网、不写库。长文、预设与自定义共享`SourcePageGallery`，显示成果名、原文页码、图注、来源，支持放大、PNG和原件下载；独立HTML导出保留嵌入PNG并移除会话依赖的原件按钮。生成图仍由现有绘图Skill和图表接口负责。
- **原件下载**：`GET /api/v1/research/{session_id}/source-assets/{asset_id}`仅在本人报告可交付、当前来源及同版本正文可用时释放实际PDF，UUID仅作定位，不能跨根或替换原件。以程序生成文件名附件下载，`private, no-store`。
- **资料包下载**：`GET /api/v1/research/{session_id}/source-package`仅用已保存内容，在打包前及释放前核对当前本人根和来源；无新抓取或模型。ZIP含`originals/*.pdf`、`text/source-NNN.txt`、`images/*-page-N.png`、附相对图片链接的`report.md`、同报告导出`report.json`与独立研究清单`sources.json`。没有把简陋文本HTML作为原交互式报告的替代；完整样式HTML仍从现有“下载HTML”导出并自含PNG。来源数≤256、正文总量≤24MiB、总文件／ZIP≤128MiB；文件名均由程序生成，来源标题不成为包路径。未保存原件的HTML、内部资料或搜索片段在清单明确原件缺失及覆盖类型，保留已有正文／权限语义。
