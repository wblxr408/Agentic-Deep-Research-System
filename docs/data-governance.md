## 已接入的基础路径

2026-10-24云端接续16.12a：访问能力识别补齐标准OAuth片段参数及SPA hash路由内参数，同时识别`id_token`／`session_token`。普通`#page=…`、章节锚点不按凭据处理；敏感片段及其值从展示／模型投影URL中移除，真实owner输入仍保留在原权限边界。相同规则沿既有`source_observation`、搜索／代理拒绝、模型派发、MCP、归档与披露出口生效，结构化及带引号赋值的身份／会话token也脱敏。HTTP不发送fragment不代表可以把它公开交给搜索或模型。此为现有规则补全，不新增登录、浏览器认证、重定向授权或渠道；原冻结策略身份和原预算／期限不重置。仅人工源码及文档审阅，未运行任何检查或业务场景，16.12a综合验收仍未完成。

`app/data_governance.py`提供版本化普通函数和DataPolicy。公开／内部／机密／受监管资料分别记录；请求声明、已选认证渠道、内部资料、实际源传输、带访问能力的URL、已知凭据形态及明确保密行标识共同提高限制级别。公开标签不能降低已观察限制，识别结果不是真实性／许可认证，也不是完整语义DLP。

QueryOptions.data_policy冻结input_class、max_model_class和最多16条public_search_queries；原问题被声明公开时加入已允许的公开查询，明确对象／时间／术语变体由现有规则生成。工具交接保留冻结策略、当前实际级别与允许查询／URL的身份，不把私有正文作为公共搜索上下文。已有非公开材料后的新外网查询需匹配允许集合；来源范围及公共网络地址校验继续独立执行。

模型阶段用当前实际证据重新派生限制级别。RoutingPolicy.endpoint_data_classes、各候选data_classes、任务上限及备用许可取交集；原internal映射现有private路由，机密／受监管需服务端明确配置。默认主端点保留public／private，非公开备用仍需allow_private_fallback及对应类别。初始化、能力升级和绘图沿同一根预算，不引入额外模型或端点。

BudgetedClient在真实供应商请求及预算预占前检查资料上限与路由类别，递归处理messages／tools等实际参数。访问凭据字面量阻断；URL的敏感查询参数及嵌入凭据从模型输入投影脱敏，原任务材料保持原位置。判断事件仅记录类别、原因及脱敏计数，进入原预算账本，不记录凭据值。未知价格和不明用量规则保持原语义。

ChannelService按实际后端为SourceItem标记分级，SearchResult／BrowserResult及最终Evidence传递。已知认证／不明传输提高为内部；匿名HTTP本身不保证内容公开。带凭据URL只走原pinned HTTP原文读取，禁止交给Jina／平台代理或DOM资源链。模型看到的脱敏URL只在精确匹配本任务owner原始输入时还原为原工具请求，不用脱敏URL获取另一份资源。公开原文归档要求当前分级为公开，同一受控传输不再单独构成足够条件；任务缓存仍沿同owner／任务／来源版本／时效和当前权限。

查询面板已增加输入类别、模型资料上限及可公开搜索的查询；预览显示初始限制级别，后续真实材料可提高限制。数据拒绝进入独立data_governance类别，作为终态工具拒绝，不按临时数据库故障反复尝试。

## MCP ACI与披露出口

McpToolRequest由原绑定工具节点传入当前network_context.data_class／policy_id。注册表secret_policy_json的allowed_data_classes默认仅public，tool_data_classes按工具额外交集；显式空列表拒绝全部，无效配置拒绝调用。资料许可、工具白名单、schema、读写审批和服务器fingerprint分别检查，read-only不授予资料外传。实际参数含凭据或敏感URL时拒绝，不把脱敏参数改作真实调用。工具返回在schema判断后按原注册表规则及统一披露规则投影，根工具安全记录保留类别／策略身份。当前默认executor=None，不宣称已连通任意私有MCP服务器。

例如注册表可声明`{"allowed_data_classes":["public","internal"],"tool_data_classes":{"lookup":["public"]}}`：lookup仍只能接收public。资料拒绝返回terminal_error／data_governance，不要求用户用一次写审批绕过此限制。审批仍绑定原参数摘要及服务器身份，展示投影不改变授权输入。

`app/disclosure.py`是普通展示函数：处理已知API凭据、私钥块、凭据字段／赋值和URL访问参数；结构化日志在渲染前投影，普通logging记录和异常栈在输出前脱敏。SSE在进入实时队列及重放历史前处理整个事件；这不是以单个chunk规则宣称能识别任意跨块秘密。Report保留供应商stream及真实计量，但不把候选报告／引用立即推到浏览器；完整语义审核、根预算和披露检查结束后才发完整正文及引用。正文需要脱敏时暂停修订，保留脱敏草稿并标记需要重新审核，不悄悄改掉已审核文字后沿用支持结论。阶段进度仍可见。

引用先投影完整保留文字再取展示摘录，敏感源URL不生成可点击链接；locator的原始字符范围仍指向原任务材料，展示摘录可能因脱敏与原文长度不同。原文读取继续走本人权限接口。完整报告发布前再次复核当前来源范围，生成期间来源变化则暂停，不发布旧依据的新完成稿。工具错误／结果摘要先脱敏再截短，AgentTrace／报告中断响应及历史草稿使用同一规则。

GET研究结果对报告、引用及研究记录进行展示投影；`export_view`为服务端显式构造的adrs-report-export-v3，JSON下载只消费此视图，缺失时提示重新读取。Markdown／HTML／打印消费对应脱敏阅读视图。历史版本在保存及读取时投影；旧正文需要改写脱敏时视为saved_draft并要求重新审核，不能继续作为审核完成稿下载。已有历史存储不在本次读取中覆盖。

## 原材料、持久化与支持范围

真实原材料和用于续作的输入不是展示副本：任务快照／请求、原工具参数、来源URL、证据文字、版本身份与原位置继续在原owner数据域保留。研究结果的`restart_parameters`仅为已鉴权本人配置编辑提供真实输入（含原query），明确排除在export_view之外；复制创建新任务仍重新预览当前许可，不继承旧审批。展示投影不覆盖这些材料，也不冒称实现了对全文、URL和快照的全面加密。

新增报告历史在原owner／execution事务内保存脱敏投影，仍绑定原来源版本；原始证据账本不受报告脱敏重写。来源的tombstone、有效期和显式purge沿现有生命周期，来源清理不等于删除历史任务材料。当前不新增自动删除／加密迁移／租户KMS，部署的数据库、备份及本机文件访问范围仍需按实际环境管理。

- 现有身份是本机单管理员／会话及服务凭据、owner数据域与生命周期，未新增企业SSO、物理租户或跨组织身份系统。候选机制按具体部署需要另选，不伪造已支持。
- 自动类别采用有限明确规则；未知敏感语义、来源许可及法规标签需要显式资料声明和实际部署规则，不给出法律合规或安全认证承诺。
