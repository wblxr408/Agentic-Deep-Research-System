# 机构名称与发表身份交接

## 实际问题与目标

c036真实旅程已取得论文全文，但选定对象只有中文名、英文署名不在别名中；FastServe的完整日期同时命中了日／月两种解析。另有模型把只有年份的证明填成月份、把多个作者拼进一个字段、在署名引文中插入省略号。这些不同原因不能统一放宽。

本模块以原短问题和相同范围为下一次完整旅程输入：实际发现并读取机构语言入口，在逐字原文支持下关联不同语言名称；成果保留实际作者／日期及精度，完成后续演进、判断、审核、图文、导出和重开。基线是上述真实失败，不在旧响应上重放新函数，也不增加子项检查。

## 工具与分析分工

新根冻结`entity_identity=official-language-v1`。选源只跟随用户显式机构入口当前实际提供的语言链接，仍通过原来源／出站准入，消耗原12项／3层读取限制及最多4项身份入口名额。语言页优先读入不代表它是科研成果，也不增加Agent或模型阶段。没有语言入口不猜译名或编造URL。

5013269f完整旅程取得12份正文，但官网实际语言链接为HTTP，被原HTTPS准入拒绝；英文名称未取得，最终32,687 Token／21请求、3抽取步骤后零成果暂停。不是机构主页返回先后导致的已证实问题。后续新根另冻结`identity_transport=https_same_target_v1`：只对显式官网语言链接，保留原href，并尝试相同主机／路径／参数的HTTPS读取地址；不执行HTTP、不改主机或猜路径，端口非默认、含凭据或非法地址不转换。读取仍重新通过原准入，成功前不认定资源等价或名称有效。manifest同时保留原href、实际读取地址、转换依据及身份入口信号，旧根不升级该规则。

`app/organization_identity.py`将已取得的显式入口、其同域语言链接及受控的实际请求／重定向信息绑定至原entity_id；搜索片段、任意同域文章和跳往外域的页面不能建立别名锚点。`identity_aliases`仅接纳这些页面的原文名称与页面标题，记录来源proof、原entity_id及校验依据；不改原请求，不把网页当作指令。名称冲突保持缺口。域名与官网入口是当前研究的身份依据，不声称独立验证了网站所有权。

既有第一次发表抽取同时装入这些身份入口；校验通过的名称交给后续抽取批次。最终成果构建仍用原配置和当前证据重核别名；原文来源撤回、改变或缺失时不能靠历史名称通过。候选机构的别名也须在原身份证明中逐字出现。

695bfa7b完整旅程已经取得并装入官网英文页，但模型返回空别名；因此当前标题／开头原文中的名称由程序形成候选，直接复用上述相同的来源、标题、逐字proof和冲突校验。纯首页、University／Company等通用词不形成宽泛署名别名。模型可补充有同等证明的候选，但不再掌握是否保留已取得官方名称的决定权；没有额外模型调用，也不从论文署名自行翻译出机构身份。

每条署名只表示一位作者，原机构名和引文保留原语言。署名proof允许1600字符的连续原文，以容纳编号作者与机构块；不接受模型拼接或插入省略号。源位置校验不代替编号对应关系的语义审核。日期解析忽略完整日期内部的较短月／年重复匹配，保留其他独立日期的歧义拒绝；支持实际非补零数字日期。只有年份不补月份，会议范围不提升为精确发表日。预印本版本日期单列依据，不宣称是首次发表日。

## 恢复与边界

问答种子升为v5，旧v3／v4分析不跨新身份处理复用；旧快照与费用保留。补证后的材料发生变化时重核成果，不能绕过反思指出的真实归属矛盾，也不能因为首轮分析完整便直接发布。原权限、用量、期限、尝试和完整审核继续约束后续处理。

沿用A2ABreak **v1.0**全11项既有评估，本增量采用：**A2AB-03《上下文归属与跨租户隔离》工程1—3**（当前根／证据／机构ID）、**A2AB-05《产物分块校验与断流恢复》工程1—4**（原文proof及完整批次）、**A2AB-06《并发状态版本与审批绑定》工程1—4**（冻结策略及v4输入）、**A2AB-08《结构化授权请求与权限不放大》工程1—4**（原来源及网络准入）、**A2AB-10《委派环路检测与全链预算》工程1—3**（原读取限额及账本）、**A2AB-11《中断任务租约与有界资源回收》工程1／4**（原期限及有界重试）。01／02／04／07／09沿原评估，无新增跨组织身份、Agent Card、Webhook、换证或新代理控制面。这些是待项目实际验证的工程建议，来源沿既有Basic Memory main方案索引。
