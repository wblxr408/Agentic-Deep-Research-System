# 组织研究的成果抽取与报告 ACI

本接口消费已经取得的任务证据，在现有 Analyst 调用中提出结构化记录，由普通函数校验原文位置并计算样本统计，再接入现有 Report。它不新增 Agent、模型调用、网络服务或数据库表。入口仍为带 `organization_research` 的 `POST /api/v1/research`，结果从本人会话读取，配置冻结规则见[运行契约](organization-research-runtime.md)。

## 输入与处理

分析调用在原预算内接收冻结的组织范围，以及最多 20 条、每条最多 7,000 字符、正文合计最多 28,000 字符的证据片段。片段保留真实 `evidence_id`、来源和截断标记。报告保留模型判断与结构化计算的区别；扩大上下文不扩大工具权限或预算。只有给到模型的片段 ID 才进入 `analyst_excerpt_evidence_ids`，`available_evidence_ids` 仅表示任务中存在的来源。

Analyst 的 JSON 根对象包含 `analysis_text` 和 `organization_data`。后者可包含候选实体、发表记录、研究家族、隶属关系、成果关系及推断／建议。记录使用原文摘录和证据 ID；无依据字段留空，不生成发表日、当前任职、正式协议、版本关系或评价等级。原始 JSON 优先解析，仅外层代码围栏可解包，正文字符串中的代码围栏不改变响应结构。抽取状态和结束原因保存在 `extraction`；无结构化结果会成为待核项。

每条发表记录包含标题、成果类型、发表日期及其原文、作者与发表时机构的共同摘录。程序检查证据 ID、原文匹配和字符区间、主页面标题、日期依据、实体名称／别名及引用关系。日期只有年或月时保存上下界和精度；整个日期区间均须落在请求时间内，不能用抓取时间或虚构的 1 月 1 日充当精确发表日。隶属继承必须覆盖整个发表区间，无起始依据的关系不用于历史继承。

隐藏的出版引用面板会保留平衡的 BibTeX 条目，并去除父子面板重复。程序可从同一作品条目的 `year`／`month` 或明确的 citation 日期元数据定位日期；如 `2024` 与 `jul` 对应 2024 年 7 月，保存两处真实字段位置和 `date_basis: publisher_fields`，不接受模型自行拼接省略号作为原文。模型只摘录短标题时，可在同份原文中另行定位完整标题；定位失败仍待核。没有这些可解析字段时，继续要求逐字日期摘录。

2026-10-21 增补明确 `Published`／`Published online`／`Publication date` 标签的英文日期识别，并兼容 ISO 元数据斜线分隔。新增英文路径只使用首个明确发表标签，不从 Received／Accepted 或后续更正日期中挑选碰巧匹配的字段；保留原文字段位置和模型声明的精度。实际材料期刊已从原先的日期拒绝修复到 `2026-07-10`，见[跨学科场景](acceptance/organization-cross-domain-20261021.md)。该场景验证英文 Published 路径；斜线元数据、其他语言和所有出版商格式未独立覆盖，字面位置核验也不代替独立语义复核。

候选实体保留来源及 `pending` 消歧状态；不凭名字相似合并。作者机构摘录无法唯一对应对象时保留待核。共同署名生成 `coauthorship`，不生成正式协议或资助。资助／引用及版本家族需要各自的明确出处；标题相似不作为研究家族证明。

## 结果字段与计数

| 字段 | 语义 |
| --- | --- |
| `object_views`、`evidence_count` | 保留兼容的名称提及／来源定位视图，计数单位仍是证据 |
| `scope_result.views` | 各对象的直接、继承、发表记录及研究家族视图 |
| `scope_result.summary` | 对象视图成果／家族并集；共同成果不按机构行相加 |
| `publication_metadata` | 成果类型、出版年、可取得的载体、证据 ID 与去重依据 |
| `comparison_groups` | 按请求学科口径、成果类型、出版年分组的样本家族数；不作统一质量排名 |
| `source_checks` | 原文 `start`／`end`／`quote`、来源、可用证据和实际展示的片段 ID |
| `pending_records` | 无法采纳、日期／身份冲突、原文缺失、格式或容量限制等原因 |
| `relationship_coverage` | 共著、资助、引用分别显示已取得样本或 `not_established` |
| `inferences`、`recommendations` | 带依据的模型解释／建议，状态为 `model_interpretation_requires_review` |
| `attribution_status`、`coverage` | 已有来源支持的样本／未建立归属样本；不表示现实全集 |

同一主出版页的重复记录合并机构与证据，日期或标题冲突保留待核；不同页面不因标题相似自动合并。未取得版本关联的发表记录按独立研究单元计数，保留 `unlinked_publication_count`，不声称已完成全网版本消重。共同署名采用全计数，各机构可以各计一次，联合汇总只计一次。

学科标签来自请求，而非已经逐篇完成的学科分类。没有取得的资助、引用或协议不解释为现实不存在。公开评价目录的存在不等于指标已应用到本批成果；自动评价、特征评分与匹配消费仍有后续任务。

## 报告、保存与错误动作

Report 接收同一份结构化结果作为分析依据，生成正文后追加由代码渲染的对象计数、同口径组、成果及来源、缺口和带依据建议。追加内容与 API 快照共用数据，并发送到原流式输出；不会由模型再次计算这些表。报告最多列出 50 条成果、30 个比较组和 20 条待核／建议，完整结构保留在结果快照。发表日期区间与精度同时展示。

原文位置与算术检查不等于独立语义审查：原文出现某词不能单独证明模型解释正确。`source_checks.status` 明确该区别，报告审核记录另注明确定性附录的验证范围。模型正文仍需按证据审阅，不能将附录存在当成整篇报告审核通过。

结构不合法或引用、日期、身份不符时按记录放入待核清单，其他有效记录继续处理；抽取整体缺失时保留空样本和明确原因，不报成机构零产出。来源不可用时由原取证流程记录失败；本计算阶段不重试网络、不主动扩展范围。取消、超时及费用沿用原工作流；重新取证需要新的研究动作，不在计算函数里隐式调用工具。

沿用 A2ABreak 基线 v1.0 的全部 11 项既有适用性评估。本次复用 **A2AB-03／上下文归属与跨租户隔离**、**A2AB-06／并发状态版本与审批绑定**、**A2AB-08／结构化授权请求与权限不放大** 的“工程解决方案／验收办法”：结果留在原 owner 会话和运行快照，范围不构成授权，确定性计算不出站。原文是数据，不能修改可信的对象／权限配置。方案出处及已验证和未验证边界见[运行 ACI](organization-research-runtime.md#a2abreak-引用与本次边界)；没有新增 A2A、Agent Card 或外部委派，不能据此宣称整套安全方案已通过验证。
