## ACI 与执行点

`app/llm_budget.py`为普通任务内对象。根图按原`budget_state`派生阶段额度，经`BudgetedClient.chat.completions.create`在实际供应商调用前执行。Planner/重规划、Analyst、Reflection、Report及最终审核均接入；备用尝试沿同一额度再次准入。没有新服务、库或存储表。

输入包括根剩余额度、阶段用途、最终审核保留、截止时间及真实messages/max_tokens。只支持当前纯文本、单completion请求；多模态或多completion需要对应计量适配器。名称、源文本、Skill或模型输出不能增加配额。

请求前按UTF-8文本字节加封装余量保守预占输入，并收紧供应商max_tokens输出上限；若剩余输出不足以完成基本回复，拒绝外发。该预占值不是精确分词器。返回的原生usage优先结算；没有usage、超时、断流等不明消费保留预占。原生usage异常高于阶段额度时如实保存并停止，不能裁剪计数制造表面守约。关闭受控SDK自动重试，显式备用模型每次单独预占；流结束或异常关闭流资源。

每阶段的用量与请求记录保存在原根状态；Token总数包含全部阶段和工具用量。历史未分类用量作为保守下界保留，恢复不自动重置。已知与不明消费分别展示，未知价格标为`unknown_price_or_usage`，费用字段的已知部分不等于账单。
