## 职责与结构

`app/organization_trends.py` 复用既有 Analyst 与已取得原文，为选择 `evolution` 或 `validation` 的任务装配趋势字段；不新增 Agent、模型调用、取证来源或自治循环。每项绑定已选对象，区分来源观察、有界推断、未来情景；保存支持片段、反向片段、替代解释、条件、时间范围和来源角色。字面定位不是语义核实，域名数量不代表材料独立性。

来源角色依据实际保留 URL、已采纳主成果及冻结官网域名声明生成：论文、预印本、声明官网、专利文档、数据／软件仓库或其他来源。调用方不能通过把文字写成“官方”把一份论文升级成部署证据；官网域名声明也不独立证明发布者身份或每项内部事实。

观察中的数值须在所引原文中出现。推断和情景须有替代解释；未来方向必须使用情景类型，具有非空条件及证据截止日之后的有效期限。缺反向材料明确列为缺口，不能说不存在反例。替代解释和条件都是待验证假设，不能当观察事实。

投入或部署的来源观察需要实际取得的适用官网材料与明确事件措辞；论文、数量或专利只能提供相关线索，未来计划不能冒充实际部署。即使通过字面条件仍需独立核实。高校／实验室可从学术问题、方法、平台或社会应用解释价值，不强制企业产品页。

覆盖快照保存已知样本年、来源数、分类版本及样本基线计数。两个年份只说明存在多个样本年，不能证明来源覆盖相同、纵向数据充分或趋势已成立；未覆盖年份不补零。报告前绑定本次实际 corpus，与来源／分类变化分别解释。完整跨图表统计继续由 7.8 实现。

## ACI 和预算

`organization_data.trend_observations` 最多 50 项；每项支持和反向片段分别至多 6 条，每条至多 2400 字符；条件／替代解释各最多 8 项、每项至多 1000 字符。传给 Report 的关系／趋势上下文有界截取，完整结果仍持久保存，不据截断推断零值。

`GET /api/v1/research/{session_id}/trends` 返回新研究保存结果，旧研究只给原有证据投影，`persisted=false`。`POST /api/v1/research/{session_id}/trends/preview` 接受有界提案，使用本人保留原文、不替换资料、不联网、不调用模型、不改原报告或预算。认证、归属、已完成状态及 401／404／409／422 沿用共同分析读取边界；不支持或缺证的提案进入待核，不自动补证。

主流程冻结趋势规则版本，保存到 `organization_result.trend_view` 和报告摘要；界面、Markdown、JSON 和离线 HTML 表达观察／推断／情景及缺口，不将情景变成确定内部计划。
