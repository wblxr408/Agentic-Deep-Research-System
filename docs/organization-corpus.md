# 样本基线、来源与流转 ACI

新组织研究使用 `adrs-organization-run-v4` 冻结 `corpus`，样本结果为 `adrs-corpus-v1`。本项把“打算检索什么”“实际取得什么”“哪些发表记录可以纳入”分别保存；不将网页、搜索线索、发表或研究家族混成一个数量，也不以受限样本冒充现实成果全集。

## 日期取证的精度与依据（2026-10-24增量）

纯年份片段也要求只有同一个明确年份；出现互不一致的年份不择取模型提议。ISO日期须有独立词边界，标识符内的数字不充当日期。此为现有日期契约的源码收紧，未运行局部检查。

U3的GNoME页面实际保留80280字符，含Methods约37000字符、Conclusion约1800字符及References，但结果正文名为Main，旧规则因此只标页面文本。新读取认识独立Main标题；Nature原始文章还须有出版题名元数据、至少2000字符Main、实质方法／结论、参考文献且未截断，才记录对应HTML正文依据。目录／摘要页不据字数直接升级；正文取得不代表模型已读全文或图像／补充材料完整。旧来源不回填，待新完整旅程证明。

A6真实研究已取得DistServe、dLoRA、LoongServe、RLHFuse原文，但英文月份／日期范围未被ISO字面匹配认可，导致发表采纳数为零。`organization_findings`现按实际日历解析英文月名、月日范围及ISO日期；仍先核对原文片段、主论文标题与发表署名。含Received／Accepted／Revised／Correction的片段不作为该论文发表日期，歧义或非法日期不采用。

正式会议论文的首页论文集／ACM引用块可支持论文集月份或年份，记录`conference_proceedings_month/year`依据，不能据会议活动日期声明精确发表日；普通日期记`literal_publication_date/year`，出版元数据仍优先。模型的原提议保存在`proposed_publication_date`。年精度不因范围截止日在年中而自动细化或默认为一月一日，交叠仍保留待补证；抽取要求使用原文实际支持的最细精度。不同日期的片段不通过择取匹配值化解冲突。源码改动不改写旧根结果；须后续完整研究验证实际采纳、统计、图表与报告。

## 声明与输入

`POST /api/v1/research` 的 `organization_research.corpus` 可省略，默认采用原渠道和出站边界下的检索与对象种子。不显式设置来源范围时，不自动套用出版商白名单。旧 v3 结果不补写今天的样本声明。

| 字段 | 含义、默认和边界 |
| --- | --- |
| `collection_mode` | `search_and_seeds` 默认；`seeds_only` 只读声明种子，不扩展搜索或自动跟进链接 |
| `seed_urls` | 最多 16 个公开 HTTPS 网址；空时使用各所选对象第一个来源。只读种子必须有可用种子，保留原列表及去重后的有效列表 |
| `search_terms` | 最多 16 条，每条 1–500 字符；空时以研究主题为声明。保存原声明和真实工具执行式，二者不必相同；只读种子时声明不会被执行 |
| `output_types` | 可选成果类型集合，空表示不额外限定；保留 conference_paper、journal_article、preprint 等既有成果类型，非法值拒绝 |
| `source_scope` | 可选复用 `ResearchSourceScope`：publishers、dblp、arxiv、google_scholar、official；出版商域名可指定，official 必须有明确机构域名。目录、域名和用途写入本次快照 |

对象名称、别名、组织类型、学科、主题、日期和截止时间沿用本次组织范围与请求冻结时间。原文支持的标题、署名和发表日期用于当前纳入检查；主题／学科仍为请求标签，独立分类由 7.3 完善，不能把声明当成已核定标签。

工作台“声明样本与来源范围”提供采集方式、出版商或机构域名、种子、检索式和成果类型配置；完整五类来源可由 API 组合。Google Scholar 只作发现，不作直接可读证据；不能把索引或预印本域名填进其他组来升级其用途。来源限定目前支持网页传输，和其他平台渠道组合直接返回 422；不以悄悄忽略渠道代替拒绝。源分类不证明某网址确实代表声称的机构或出版商。

## 取证与执行边界

选择只读种子时，普通函数按去重后的种子生成公开的读取步骤，无需再调用规划模型扩展任务。选检索模式时，Planner 仍规划本次问题；受限搜索附上域名条件，返回结果再按范围过滤，保存实际查询与被过滤的线索。搜索片段标为 `discovery_only`，不能充当主要成果的原文证明。

浏览节点在读取前及每次重定向前使用冻结的来源范围，并复用已有 `HttpReader`：HTTPS、禁止 URL 凭据、检查全部解析地址并锁定允许的公共目标，最多四次跳转，每次响应最多 8 MiB。受限路径只取指定来源正文，不加载页面脚本或外部资产，不自动跳转全文 PDF，也不通过其他代理放宽范围；动态页面读不到时保留错误。模型生成的其他种子、非适用传输或 MCP 路径不能绕过限定，记录为终态拒绝。

冻结配置必须显式进入并行 `Send` 工作上下文，不能只留在根状态。浏览节点仅取得本网址对应的任务内已读证据；只读种子重规划时可复用同一任务已保存的 `pinned-http` 结果并记录 `reused_task_evidence`，保留来源时刻，不新增重复证据。不存在跨用户或全局 URL 缓存。新研究重新采集；改权重重排仍不改写原样本。

HTML／普通页面文字不自动成为已取得全文。显式种子为 PDF 时复用已有有界解析器，保留页数、位置和截断；只有完整保留的可解析文本才标为全文，扫描无文字、截断或不可读取均保留相应缺口。该 PDF 分支不是 HTML 样本端到端通过后自动获得的验证结论。

## 样本结果

`organization_result.corpus` 与报告摘要采用同一保存结果，包含声明、冻结／评估时刻、实际执行查询、候选记录、流转阶段、采纳／排除／待核数量及全文状态。无证据也保留种子和未取得状态。

| 状态 | 解释 |
| --- | --- |
| `candidate` | 声明或发现的来源线索，或尚未满足原文、日期／身份条件的发表候选；不视为已纳入成果 |
| `accepted` | 通过本次既有字面原文、引用、日期和归属检查的发表样本；不代表独立语义审核或现实全集 |
| `excluded` | 有明确范围排除依据，例如已核对出版日期在范围之外、提出的成果类型不在选择中、来源不在白名单；保留理由，不能默默丢弃 |
| `full_text_status` | 与采纳状态独立。只有取得并完整保留的全文为 acquired；没有已确认全文时显示缺口，不能声称完成机制深读 |

对单个 BibTeX 记录且页面标题一致的出版页，程序保留字面标题、年／月及原文偏移，按原精度建立日期区间；可据此记录模型漏提的明显范围外条目。日期区间完全在外才排除、完整在内才可纳入，交叠而精度不足保持候选；上下界不冒充实际发表日。多个 BibTeX、标题不一致或不支持格式不猜测，保持待核；这不是所有出版商元数据适配或语义核实完成。

来源候选按规范化主来源 URL 去重（去片段、已知追踪参数、尾斜线），保留原声明中的重复数。发表和显式研究家族仍分别计算；没有关联依据的不同来源／版本不按标题相似强合并，也不声称完成 DOI 镜像全局去重。候选网页数不作为论文分母；缺年份、未覆盖时间和未取得全文不补零。

页面及 JSON 保存全部记录与流转，Markdown 追加同一基线表；HTML 继续复用实际报告预览。原始配置和采纳事实不随偏好重排改变，显式“重新取证并研究”继续携带原样本输入，重新冻结截止时间。无效请求返回 422；获取或解析失败保留原因和待核，不自动放宽范围。
