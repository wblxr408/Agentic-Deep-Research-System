`organization_findings.build_organization_findings`仍检查当前主成果标题、实际日期区间及范围、同一作品的逐作者署名和机构唯一对应。核心结构、引用、日期、署名不成立时继续拒绝该成果。可选venue的结构错误独立记录为`publication_field`，核心结构仍需完整合法；可选venue必须有当前正文、同一主成果及其开头原文里的quote，文件名／URL和参考文献不能补证明。失败时venue为null，候选及原因留研究记录，正常报告不复制运行错误。

## 字段v3：当前原文的排版与作者交接

36e840ca再次整块运行，已保存三份原PDF，但标题标点空白、多人单字段及不同署名块的字段／quote错配使成果整体未获准。新根改冻`adrs-publication-fields-v3`与问答v8，保留v2附加字段规则；旧v2根不升级，仅已完成v5／v6／v7问答可在原精确binding及原恢复边界下继续报告，旧暂停不能混入v8。实际失败与用量见[旅程记录](acceptance/source-media-20261029.md)。

`publication_literals.literal_pattern`把原文字词和标点分为字面token，相邻文字token仍必须有空白，标点旁允许排版空白差异。所有文字、符号、数字和顺序保持，不删除连字符、不连接不同单词、不翻译或展开缩写。匹配后保存实际source字符位置及原字串，而不是模型改写串；输入≤5000字符，根校验实际proof跨度≤5000。新策略的成果、深读、关系、演进、行动与判断共用`source_pattern`，旧策略继续旧匹配；数字支持、来源身份、全文和实际选段范围不变。模型quote与实际位置有排版差异时留`source_normalizations`，最多64项。

`publication_affiliations.direct_cover_pair`不根据机构名猜作者。只有当前同一作品主开头内存在唯一、连续、字面明确的`作者, 机构`，且≤1600字符时，才可替换模型指错的proof；不换作者／机构／来源，不去其他页面补关系，也不在正文或参考文献里寻找替代。新proof仍经原校验，原proof保留在规范化记录。

`shared_author_names`只处理已明确提供的3—12个完整姓名，逐一要求当前原proof内唯一出现、顺序一致、随后只有同一原始机构；除可选题名、所有这些姓名、该机构外，剩余只能是排版／贡献标记。任何其他作者、机构、文字、位置冲突、缩写猜测或不完整名单都会阻止展开；不把普通逗号姓名普遍拆成新人物。展开后逐作者继续核对原proof和机构唯一身份。没有新增论文、作者候选、模型或检索轮次，原始响应和恢复事件均保留在研究记录。

这两个小型普通函数分别替代散落的空白匹配和重复复制的作者字段，不引入解析框架。新边界源码与调用链已审阅，尚未在原raw上重放、运行示例、局部或回归检查，也未据此将图文交付或源语义标为已通过；最终完整业务仍须证明实际成果、分析、判断、全部主张审核、图文及重开。安全条目沿上节A2ABreak v1.0及同一当前原文／字段／冻结输入／预算执行点，无新控制面。
